# 构图参考与艺术字研究

此GitHub发布版仅分发技能规则及校对脚本，不包含原私人技能包中的第三方海报、文字参考图片或图标。使用者可提供有权访问和使用的实例、构图线框及文字组合参考；未提供或不可访问时按[平台适配](12-platform-compatibility.md)处理，明确记录参考未查看，不虚构文件数量、来源、版权或阅读结果。

## 实例研究

生成底图及候选前，实际查看当前可访问的相关领域实例，通常选择2–3张进行细读。记录来源、领域、构图、色彩、主体表现、空间层次、留白、标题与图形关系，提取结构而不复制原作。不同图包的领域编号可能不同，按领域名称匹配。线框只用于理解信息顺序，不作为最终皮肤或真实图片的替代。

第三方海报不裁切抠图、去水印或作为正式成品背景，不移植其中的电话、机构、地址、品牌或活动内容。普通图标的获取与许可见[素材来源](06-icon-sourcing.md)。

## 艺术字与配套正文

每种所需语言先独立生成3款横排＋2款竖向组合艺术主题字并选择；有文字组合参考时实际查看并提取结构。中文竖排字符正向、每列从上到下且列从左到右；英文竖向组合保留完整横向词组，不逐字母竖排。竖排标题按风格规则省略标点，原母本和展示文案分别保留。

主题字选定后，优先使用当前平台图像生成工具生成同风格正文、地点时间与电话文字层，由AI逐字校对、修复，直接合成3–5张完整排版候选，不设正文批准关卡。工具能力不足按[平台适配](12-platform-compatibility.md)处理；替代字体／矢量排版如实标明，不冒称生成艺术字。艺术字、完整信息、数字和可读性一起检查，参考风格结合实际事项语气；不得因艺术处理改变标题含义。

候选中保留至少一份普通标题对照，同时有3种明确的位置与版式变化。完整母本保留可编辑来源；生成字形位图与可编辑字体不能混称。具体流程见[主题字与整体排版](11-type-selection-and-layout.md)及[位置与留白](10-position-and-whitespace.md)。

## 顺序与选稿

先展示3–5种实际底图并明确提问选择；再展示独立主题字并另行提问；选定主题字后制作完整排版，再单独提问选版。用普通对话或平台选项组件均可，图片先展示，不凭推荐或沉默代选。用户已有选择或明确要求跳过探索时直接沿用，不能发起无实际图片的空选稿。
