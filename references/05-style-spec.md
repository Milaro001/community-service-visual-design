# 五大家族风格基线

这是原课程项目提供的风格参考，作为默认探索基线，用户当下的品牌与风格要求优先。不存在自动继承到所有项目的永久冻结；选稿后记录本任务颜色、字体、字重、图形语言和参考依据。

|家族|领域|主色/浅色|气质与排版|
|---|---|---|---|
|F1|D01/D02/D06|#315F74 / #DDE9EC|规范可信，左对齐网格、清晰编号|
|F2|D03/D04/D05|#3C776F / #DDEAE6|温和可靠，大字与留白；不把建议作诊断|
|F3|D07/D08/D15|#A66F32 / #F0E4D2|实用亲切，费用清楚；不藏进小字|
|F4|D09/D10/D13|#A64941 / #F0DDDA|克制行动，强调风险；不恐怖化|
|F5|D11/D12/D14|#66547E / #E7E1ED|开放包容，稳定信息网格|

共用米白#F5F3EE、深墨#17202B、灰#6F7780。这些不是标准警示色，不能替代规范符号的用色。普通标题对照及真实文本标签优先已有品牌字体或可核验授权的Noto/思源系列；检查实际字体是否可用，替代后重新测量。主题字与配套正文按独立图像生成流程处理，保留可编辑文案母本，不冒称生成图使用了某个授权字体。

文字优先：按受众和阅读媒介定字号，确保能放下再组织画面。Case03字号、坐标与黑白八版实验见 audience-layout.md，仅当前任务采用该案例时使用。普通A3可从正文27pt起探索，大字需求从32pt起探索；这是项目起点，不是所有场景的强制标准。标题按信息层级调整，不设“必须正文四倍”。

屏幕色值对比检查可采用正文4.5:1、重点信息7:1的项目目标；实际印刷、距离与目标受众仍需单独验证。背景有纹理或图片时检查局部最差区域，不只对名义背景色计算。信息不单靠颜色/图标表达。

同张海报通常控制在两种字族、少量字重与主色辅助色；必要的标准安全色、照片和信息分类可例外。图标可以单色或彩色，跟随当前风格；不能为了统一风格破坏规范图形。

候选方案展示整体视觉差异（摄影/插画、层级、留白、色彩关系），不是只发文字风格名。明确方案数量时按用户请求。参考海报中的水印、文字、机构和受保护标识不移植。

## 通用应急号码的展示范围

大众熟知的通用应急号码通常不展示，也不为凑齐联络信息自动添加。只有内容明确指向具体紧急行动（如发现火灾需报警）时，才展示与该行动直接相关的号码及用途；通用宣传中优先保留与当前事项直接相关的专业门诊、服务或投诉专线。用户资料中已有的通用号码同样按此展示规则处理，在母本变更记录中注明省略，保留原始资料；用户后续明确要求保留时按最新要求执行。

## 竖排阅读顺序

本技能的竖排中文统一采用**每列从上到下、各列从左到右**的阅读顺序。此规则覆盖主题字、正文、提示和其他竖排信息；无论文字放在画面左侧、中央或最右侧，列顺序均保持不变，不沿用传统从右到左的竖排次序。

双列标题示例：左列从上到下为“依法文明养犬”，右列从上到下为“牵绳清便登记”。多列按完整母本依次从左列排到右列。竖排标题不显示标点符号，详见下述标题规则；正文的标点仍跟随所属句段。字符保持正向，不把横排文字旋转90度。

英文竖向组合仍以完整横向词组或短句自上而下组织；若有多个信息栏，各栏也从左到右阅读，不逐字母竖排。生成说明须写明列顺序；检查时依“左列从上到下→右列从上到下”的实际路径还原母本，确认无颠倒、漏字或重复。

## 竖排标题不显示标点

竖排或竖向组合的标题不显示标点符号，中英文均适用；例如中文双列标题去掉句间逗号，英文词组竖向标题去掉“Leash”后的逗号。只省略标题标点，不改动标题字词及列顺序。原文母本保留完整标题，另记录竖排展示文案与标点省略原因。正文、警示、地址、开放时间、电话号码及其他非标题信息继续保留必要标点和格式；横排标题按母本保留标点。

## 实例与艺术字

生成底图/候选必须实际看实例海报，并从中提取视觉语言。排版阶段至少给一份艺术字主标题海报与普通标题版对照供选择，详细规则见09-reference-library.md。艺术字风格不能覆盖真实文案保真与可读性。

## 当前顺序：先底图，再排版

首次视觉制作必须先生成并展示3–5种不同风格的底图，默认3张，供用户选择。底图以实例海报为风格参考，具有主题主体、背景与文字留白；先不加入正式文案。用户选定后，每种所需语言独立生成3款横排＋2款竖向组合艺术主题字并单独提问；选定主题字后生成并由AI核验、修复配套正文，不另要求用户浏览或确认正文，直接制作3–5款不同文字方位的整体版式（含普通标题对照）并另行提问。没有选定时不自行替用户决定。用户明确要求跳过探索或同任务已有选稿时沿用其决定。

## 选择须明确提问

展示实际图后明确问“你希望选择哪一款底图进入文字排版？”并列出编号、风格和推荐理由，等待用户答复。艺术字与普通标题等后续选择也以问题呈现。可用普通对话或平台选项组件提问，实际图先显示；不能只有“供用户选择”的陈述，不能凭推荐或沉默代选。未能生成实际图时不发起空选稿。
