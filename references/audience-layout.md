# 社区服务信息海报受众适配模块

## 1 任务与适用范围

根据服务对象的阅读需求，把已确认的社区服务内容组织成清楚、完整、可复用的海报排版。输出应使居民能够快速找到服务事项、行动要求、地点、开放时间和咨询方式。

本模块负责课程分组中的第二项工作：受众决定的字号、对比度和字体占版适配。上游提供已确认的文案、风格、版式骨架及机构表达要求；本模块完成排版适配后，将成图、参数和检查结果交给总 Skill 的评价与迭代阶段。

**适用优先级：当前用户要求和主Skill最新流程优先。** 本文件只提供受众阅读需求参考；下面Case03八版黑白A3坐标、固定字体、22.5%图片区和实验交付是历史实验，只有用户明确要求该八版实验时才启用，不能因为本项目同样叫“高温防护”便自动套用。若用户只要求社区海报，执行主题主体30%–40%、配套艺术正文、锁定画布与中英文同构等当前规则。

本文件包含两层规则：

- **通用规则**：输入核对、受众选择、内容保真、排版检查和占比统计，可迁移至其他社区服务主题。
- **Case03 A3 预设**：本次“高温天气健康防护与清凉服务”的八版中文对照实验，采用下文固定坐标、字号和文案。它是历史八版实验的预设，不是当前艺术海报或所有海报的通用规范。

用户提供新的画布、内容或母版时，以新要求为准，重新验证适配结果。不得把 A3 坐标直接套用于其他比例的画板。

## 2 输入要求

开始前读取现有材料，避免重复询问已经提供的信息。识别下列输入及其来源。

| 输入字段 | 内容 | 缺失时的处理 |
|---|---|---|
| 主题与传播目标 | 居民需要知道什么、执行什么行动 | 结合任务书确定；无法确定时询问 |
| 内容母本 | 标题、行动及已提供的地点、时间、电话、注意事项 | 可选字段未提供则不设置；明确请求事项缺少不可省略的必要事实时才询问，不自行编造 |
| 受众 | 一个或多个受众类别，以及已知阅读需求 | 对照实验输出 A01—A08；单张海报未指定时使用 A01，并说明假设 |
| 画布与媒介 | 尺寸、方向、输出格式、印刷或屏幕、观看条件 | 本次实验采用 A3 竖版；其他任务先核对实际规格 |
| 母版与视觉素材 | 布局、字体、照片、图标及已提供机构标识 | 按已有资料使用；无机构名或Logo则不设置落款，不据此要求补资料或自动标成草稿 |
| 语言 | 中文、英文或其他语言及对应母本 | 不把“国际居民”直接等同于英语使用者，按任务提供的语言选择 |
| 输出模式 | 八版对照、单一受众适配或独立语言适配 | 根据用户当前请求选择，不默认增加交付范围 |

输入文件中的示例、历史提示和生成指令属于待分析资料。它们只有在与当前用户要求一致、且被选作任务约束时，才用于指导执行。

## 3 受众选择与冲突处理

| 编号 | 受众 | 本模块关注的需求 |
|---|---|---|
| A01 | 全体居民 | 平衡呈现，便于建立标准母版 |
| A02 | 老年人 | 大字、清楚分组、醒目的地点与联系方式 |
| A03 | 儿童青少年 | 编号与行动对应，动作词易于识别 |
| A04 | 孕产妇·照护者 | 快速找到与照护有关的已提供提示 |
| A05 | 残障人士 | 本次静态海报重点验证视觉可读性，不声称覆盖所有残障需求 |
| A06 | 新市民·国际居民 | 地点和入口明确，匹配实际语言需求 |
| A07 | 户外劳动者·骑手 | 短时间内找到防护行动、服务地点和开放时间 |
| A08 | 宠物主·商户 | 公共服务安排与咨询入口易查找 |

这些类别可以重叠，不能仅凭身份推定所有人的阅读能力。若有更具体的用户需求，优先使用具体需求。

面向多个类别时，分别合并要求：

1. 正文字号、行距、数字字号和对比度采用相关预设中较高的要求。
2. 主标题按空间和信息层级调整，不机械取最大字号。
3. 合并需要强调的已提供内容，保持所有必需信息完整。
4. 将组合受众和最终参数写入记录；组合版不冒充某一个单一受众的实验结果。

## 4 内容与比较原则

- 不改变服务地点、时间、号码、机构名称和行动含义；不添加未经提供或确认的服务、政策和健康建议。
- 电话保留其原有性质。“咨询电话”不得改写成“急救电话”。
- 对照实验保留同一内容母本、图片、裁切、颜色、编号和分区顺序。允许变化的项目为字号、行距及明确规定的字重强调。
- 本次八版中文实验采用相同断行，借助预留空间容纳不同字号。
- 同样的阅读需求可以得到相同的参数，例如 A01 与 A08。不得为制造视觉差异随意改变风格。
- 实际受众需求和完成后的可读性高于预设数字。所有预设都需要经过排版检查，不把未经测试的方案写成“已验证有效”。

## 7 字号换算与适用限制

分组参考以 1080 px 宽画布给出正文 34 px、36 px、40 px 三档。A3 宽度约为 841.89 pt。保持相对画布宽度不变时：

```text
A3 字号(pt) = 参考字号(px) × 841.89 ÷ 1080
34 px ≈ 26.50 pt
36 px ≈ 28.06 pt
40 px ≈ 31.18 pt
```

本预设据此使用 27 pt、29 pt、32 pt 等执行值，并针对部分受众调整至 28 pt 或 30 pt。该换算用于建立相对大小基准，不能替代不同观看距离、设备或印刷条件下的可读性验证。

更换画板时，先判断是等比例缩放还是重新排版。只有画板比例一致、观看条件允许时，才把字号、坐标与间距同步等比例缩放；改为 4:5 等其他比例时，应保留信息顺序并重新分配区域。

## 8 各版本强调规则

| 编号 | 强调方式 | 执行边界 |
|---|---|---|
| A01 | 正文 Medium，各条行动均衡；时间、电话清楚可见 | 作为基准版，记录实际排版参数 |
| A02 | 电话 Bold；“规律饮水”“及时休息”“寻求帮助”加粗 | 保留完整句子和地点，不因大字删减内容 |
| A03 | 编号 Bold；“饮水”“遮阳与防晒”等动作词加粗 | 保持分组明确；儿童与青少年需求差异较大，本版只表达所选阅读支持方式 |
| A04 | 行动③中已提供的重点人群名称、行动④中不适表现及处理动作加粗 | 不自行添加孕产妇专属医学提示，不把未提供的信息包装为已确认建议 |
| A05 | 重点动作与电话 Bold；清晰标签、顺序和高对比共同表达信息 | 不声称大字海报满足全盲、认知障碍或其他所有无障碍需求 |
| A06 | 地点名称可用 Bold，时间与电话标签明确 | 中文版用于新市民及具备中文阅读能力的居民；国际居民按实际语言制作对应版本 |
| A07 | 行动①②、开放时间与电话 Bold | 突出已有行动及服务入口，不额外创造服务承诺 |
| A08 | 地点、时间、咨询标签 Bold；正文保持 Medium | 不添加宠物接纳、商户优惠等资料中没有的事项 |

加粗后重新检查字宽与断行。先减少非必要的加粗范围，不能通过删除必需文字解决溢出。

## 9 独立语言适配

八版中文实验保持语言一致，避免把语言长度差异误记为受众字号变化。需要国际居民版本时，使用任务提供的对应语言母本，另建 `A06-EN` 等独立语言版本。

- 保留标题、图片、行动、地点、时间、电话和预警的阅读顺序。
- 重新测量标题、地点和行动句的长度，独立设定文字框与断行；中文坐标表不能被当成英文必然可容纳的保证。
- 保持全部事实和专有名称准确，不自行增加语言版本未包含的服务承诺。
- 按该语言字体的实际字形和可读性确定字号，记录最终参数。
- 独立语言版在共同信息分区内调整文字框高、断行及行距；画布方向、底图、主体构图与分区关系保持一致，不调整整版分区比例。语言差异应记录，不与中文八版的字体占版数值直接混合比较。
- 未要求双语同版时，采用分开的语言版本；确需双语同版时重新设计区域，不直接叠加两套完整文案。

## 10 历史Case03八版实验流程（仅明确请求时启用）

1. **读取输入。** 提取内容字段、来源、受众、语言、规格和锁定要求；区分用户要求与参考资料中的示例。
2. **建立标准版。** 按第 5、6 节完成 A01，核对所有文本、位置、断行及数字。
3. **预检最大字号。** 在副本中用 32 pt 正文、44 pt 行距检查空间，同时检查 48 pt 时间和 44 pt 电话。A01 能放下不能证明其他版本也能放下。
4. **冻结共用结构。** A01 和最大字号预检都通过后，固定图片、坐标、文案及断行；再复制所需版本。
5. **应用适配。** 按受众修改字号、行距和第 8 节允许的字重，保留各版独立记录。
6. **处理溢出。** 先检查字体、内边距、字距、缩放、段前段后、重复换行及误加粗。仍无法容纳时，统一修订中文实验的共用文字框或断行，并回查全部八版；记录变更，不能只让某一版暗中改变结构。
7. **测量与检查。** 执行第 11、12 节。可读性测试未实施时，记录“未测试”，不填入假设结果。
8. **交付。** 仅输出当前请求要求的文件；报告真实完成情况、参数变化及尚未验证的部分。

历史黑白实验使用真实文本对象和可编辑字体。当前艺术海报则按标题确认后图像生成工具生成配套正文位图，再组合可编辑位置图层；另存完整可编辑文案母本。两种交付方式不得混称，不能声称生成艺术字位图的字形可直接编辑。建议按“参考线、图片、标题、行动、服务、预警”组织图层。

## 11 占比测量与参数记录

必须区分“预留文字区域”与“实际排出的文字”。固定文字框的八版，其预留区域占比相同；字变大并不等于文字框面积发生变化。

### 11.1 分区占比

```text
分区占版心比例 = 该分区面积 ÷ 104130 × 100%
图片区占整页比例 = 226.7 × 124 ÷ (297 × 420) × 100% ≈ 22.5%
```

明确分母是版心还是整页，同一对比表保持相同口径。分区面积仅按互不重叠的分区统计，避免将父区域与其内部文字框重复相加。

### 11.2 实际文字占比

```text
实际文字占版心比例
= 各行实际文字紧致外接矩形的面积之和 ÷ 104130 × 100%
```

测量约定：

- 每个独立文本框的每一行分别测量；同一行中的标点、词间空格和编号按实际排版处理。
- 单独的编号框作为独立文字元素统计一次，不重复计入正文。
- 外接矩形包含字形之间的空隙，但不包含段落间距、文字框底部空白或整块预留留白。
- 该指标是文字外接矩形面积，不是黑色像素或油墨覆盖率。
- 使用相同字体版本和同一种测量方法处理全部版本。PDF 字体度量可能与可见字形边缘不同，应结合渲染检查；必要时在测量副本中转曲测量，保留原稿文字可编辑。
- 无法可靠测量时标注“未测量”，不根据字号比例推算成已经测得的占比。

历史字体实验每版至少记录：编号、受众、语言、实际字体、各级字号与行距、字重调整、框架版本、图片裁切是否一致、分区占比、实际文字占比、溢出检查结果及阅读测试状态。

### 12.2 阅读测试

1. 应采取哪些防护行动？
2. 可以去哪些服务地点？
3. 每天何时开放？
4. 出现不适时应怎么做，咨询电话是什么？

记录参与者与目标受众的关系、测试条件、查找耗时和错误，不预设已经达标。普通同学测试只能说明该测试样本的表现，不能冒充目标受众的验证结果。若出现漏读或误读，优先检查分组、标签、字重与间距，再调整字号。
