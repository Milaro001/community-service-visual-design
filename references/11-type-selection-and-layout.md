# 主题字与整体版式分阶段选择

正文优先使用当前平台的图像生成工具；文字准确性、透明层或组合能力不足时，按[平台适配](12-platform-compatibility.md)处理。以实际制作方式记录，不把替代字体排版称为生成艺术字。

## 参考资源与使用

原私人版本使用以下四类参考；此GitHub发布版不包含图片，需使用者提供可访问且有权使用的参考：

- T01 整体排版（可选外部参考）：沿边布局、角落锚点、大小字对比、横竖交错、整页留白关系。
- T02 文字组合（可选外部参考）：主标题＋侧边说明、错落断行、左右锚点、短线分组。
- T03 文字组合变体（可选外部参考）：相同内容的紧凑叠排、竖排、分栏与局部错落。
- T04 英文艺术字（可选外部参考）：粗窄无衬线、经典衬线与笔刷/手写字型等不同语言。

有相关图时必须实际查看，提取可用于当前底图的结构，并记录选用理由；没有图片时按平台适配规则记录参考未查看，不声称已看到缺失资源。不能逐张机械套模板；不照搬品牌、活动、日期、票价或原字体素材。参考图里的小字比例不适用于所有服务正文。第三方图仅供私人风格研究，不直接进入交付海报或默认拥有原字体许可。

## N5a：先选独立艺术主题字

1. 锁定完整主标题、语言、底图、目标受众、事项语气；已有资料和决定直接沿用。
2. 中文与英文分别制定生成说明、分别独立生成。英文以T04的英语笔形和词组结构为参考，不能把中文艺术字更换为英语字母或直接翻译同一图。英文横排主题字使用完整横向词组；竖向候选以完整横向词组自上而下组织成窄栏，不逐字母堆叠或将整块英文旋转90度，词距、层级、字形按英文阅读习惯处理。文字方向不改变海报画布方向。
3. 每种实际需要的语言默认5款主题字：3款横排（H1/H2/H3）＋2款竖向组合（V1/V2）；当前已有A/B/C横排候选可保留编号，另增V1/V2。中文竖排字符保持正向，每列从上到下、各列从左到右阅读；标题放在画面左侧、中央或右侧均采用同一顺序。双列示例：左列“依法文明养犬”，右列“牵绳清便登记”；不得颠倒两列。竖排／竖向标题不显示标点符号，中英文均适用；只省略标题标点，正文及数字格式保留。正文及其他竖排文字同样遵循该顺序；两款可采用齐整双列、错落多列等不同结构，不能把横排素材旋转90度冒充竖排。英文竖向组合按上一条处理。风格必须明显不重复，例如亲和立体／黑白简约／平面书写；英文可用粗窄无衬线／黑白经典衬线／手写笔刷。已符合要求的现有候选可计入，并明确为复用，不能重复生成同风格凑数量。
4. 不只是换色：同时比较笔形、装饰复杂度、图形关系、立体或平面、排布及配色。用了童趣则其他款提供成熟或严谨方向；用了繁复元素则另一款应简洁；已有红蓝对比则提供黑白或其他独立色系。
5. 各候选可有太阳、雪花等字义图形，但不替代字词。按受众和事项调整：儿童更童趣、警示更醒目、庄重事项更端正；始终保证实际标题准确易认。逐字/逐词检查错漏、重复、词距、变形、背景透明度和边缘裁切。
6. 候选阶段只展示实际主题字，不提前为用户选择并制作一套完整成品。图外标明A/B/C、语言、风格、参考依据、推荐理由。保存源资产、准确母本文案和实际生成提示词。
7. **单独提问**：“中文主题字选择H1/H2/H3/V1/V2哪款？英文主题字选择EN-H1/EN-H2/EN-H3/EN-V1/EN-V2哪款？”（沿用已有编号时按实际编号提问）可以在同一个主题字选择问题中让用户分别回答两种语言；不能把这个问题和整体版式选择放在同一次提问里。允许组合或修改，推荐不等于选择，未回复不进入依赖其选择的排版。

## N5b：选定主题字后再选整体排版

1. 主题字确认后，先依据[配套正文规则](10-position-and-whitespace.md)用 图像生成工具 生成并核验同风格正文文字层；正文生成后由AI校对并修复，直接进入完整排版；不新增正文浏览、样张确认、风格同意或批准关卡。除非用户主动要求看正文，否则只在完整候选中呈现正文。事实性疑问按母本证据规则处理，不用视觉确认提问替代事实核验。再基于选定主题字、配套正文、已选底图、完整母本和T01–T03参考，实际制作3–5张完整海报候选，默认3张；清楚记录同底图及任何为新画布必要的适配。
2. 将已选主题字、核验后的配套正文及同一底图合成3–5张完整海报，至少3张；正文原则上跟随所选主题字的横排／竖向组织，电话、时间、邮箱、英文词组等保持完整易读。版式差异来自位置、大小层级、横竖关系、分栏、对齐和信息分组，不用同图换色或单纯换字体冒充不同排版。可以采用上置／下置／侧边锚点／紧凑错落等实际适合留白的组合；不可为了凑数覆盖关键人物或缩小正文。
3. 生成前先从最初资料锁定竖版/横版、比例与尺寸。中英文画布方向、比例、底图和构图必须保持相同，使用共同标题区、正文区和服务入口。英文字符与词组保持横向阅读，竖向方案以完整词组／短句组成自上而下的窄栏，配套正文同样组织为竖向信息组，按长度调整字号、换行与行距；不得因英文横向排字而改成横版画布。中英文主题字独立生成、分别选择的规则仍有效，它不授权改变画布或主体构图。
4. 中文标题组默认占整幅35%–40%，接近50%仅作少见特例；正文按已选标题艺术风格生成，大字、行距、明暗对比和完整内容优先；只有用户要求普通字体对照时另出普通正文。服务地点、时间、咨询电话优先底部第7–9格，电话置底，数字不拆行；标题在上半部时，地点/地址与时间左下角底置、电话右下角底置，中英文保持同一位置关系；其他标题位置按留白安排。一般正文及其他底部服务信息禁用整块矩形铺底；严肃短警示和紧急号码组按最新强调规则适当放大、用不同颜色，允许紧凑红色提示框或克制渐变；小型副标题/短提示句允许参考底图和标题风格的设计矩形框；通过留白、移位、字重与主题深色保证阅读。标题风格确认后，用 图像生成工具 按已选标题实际图生成配套正文，中英文分别制作；描边遵循用户最新方案：当前暖色浅底方案按用户最新选择用白色描边，蓝色正文明度参考03/04序号主色，不强制附加阴影；底部信息整组完整可读；出现文字与底图重叠时，按局部轻微虚化底图→受影响文字等比缩小约5%→调整位置的顺序逐步检查处理，详见位置规则。正文配色呼应艺术字，编号/圆点/短横可适度放大、加粗和强调；每张候选渲染后实际查看，具体见[位置与留白](10-position-and-whitespace.md)。
5. 至少保留一份普通标题完整海报对照，可计入3–5张候选但必须说明其标题处理；仍须有3种明确版式差异。
6. 逐张检查实际导出；显示L1—L5编号与实际图片后，**再单独提问**：“你希望采用哪一张整体文字排版？” 等待真实回答再精修所选版本，不能记录未经确认的G3为通过。

艺术主题字源图可以是生成位图，但完整母本文本必须保留可编辑来源。正文、地点、时间与电话保留真实可编辑母本；依最新要求生成配套艺术正文位图并逐字核验，组合位置保持可编辑。实际阅读测试、投影测试未实施时明确记录，不以模板或AI检查替代真人结果。
