# 图标和插画风格匹配

先定语义与位置，再定视觉。读取用户参考图，记录线性/面性、线宽、圆角、色彩饱和度、视角、光源、质感、图形占比。普通生活图标优先同库同系列；缺失语义可选择近似并给文字标签，不能为了“只用一家库”制造错误含义。

图标未定稿时可用单色骨架；最终单色或彩色由本任务风格决定，不强制AI重绘。需要新插画/质感时使用实际可用生图工具，先看参考，再生成或编辑，检查是否新增文字、品牌或误导的服务细节。

规范标志、警示色、禁止符号、真实机构Logo、路线与地图不得自由风格化。按已确认源图保留语义和几何，缺来源标待核验。普通生活插画可调整风格，最终并排检查笔画、用色、视角、光源、视觉占比和识别语义。

记录素材源头与修改过程；AI改绘不自动消除原素材许可义务。能力缺失时提供可编辑构图或生成提示作为明确的未完成交接，不冒充最终图像已完成。

## 根据环境与主题选择性配图标

- 先判断图标是否帮助定位、理解或执行已有信息，再决定添加。电话、地点、时间等短信息组适合小图标；风险提醒可配语义准确的提示图标。不是每行都加，也不为图标新增未提供的地点、开放时间、服务承诺或行动步骤。
- 电话图标可用于普通联系或求助信息，急救120与报警110仍分别保留完整用途标签和号码；若没有准确的医疗／报警符号，可共用普通电话图标并靠文字区分，不能把医疗符号误用于报警或冒用官方徽标。
- 优先在iconfont.cn同系列中挑选；其次本地库，来源顺序见[来源核验](06-icon-sourcing.md)。普通辅助图标的线宽、笔形、圆角、填充方式与当前海报协调；纸艺海报不强制把所有图标AI立体化，可采用克制的面性或线性图标。经许可允许时可调整颜色和尺寸，不能改变其语义。
- 图标与对应文字靠近、基线协调，大小从接近用途标签字高起步，保持内外间距和局部明暗对比；关键号码优先，不让图标抢主标题或挤小正文。急救和报警图标可呼应各自强调色，颜色不代替文字说明。
- 组合后实际查看每个语言版本：图标含义准确、文字和号码完整、线条清楚、无裁切／遮挡、风格一致、位置对应。本任务未请求直接修改当前海报时，仅更新规则，不自动重做已展示的选稿。
