# 事实核对、母本与变更

## 输入与缺省

直接使用当前已提供资料并记录来源，不重复索取，也不固定询问“实际发布还是课程示例”。未提供机构、Logo、地点、开放时间、电话、邮箱等可选字段（含回复“无”）则不设置、不加占位；无机构/Logo不使通用宣传自动成为草稿。仅当用户明确请求的服务、活动或求助事项缺少不可省略的事实，或存在影响表达的冲突时，集中询问受影响字段并继续无依赖工作。

资料名含“示例”不自动排除其中作为本任务内容提供的字段；与本任务无关的历史安排、参考海报联络信息不得移植。用户明确保留其示例邮箱/QQ群等值时，记“用户确认的示例值”，用于明确的示例交付，不冒称真实入口，也不重复询问或自动移植到未来任务。

## 证据与直接修订

正式服务条件、政策、医疗、安全和许可信息核对适用来源。每字段记录链接/文件页段、发布方、发布日期、适用范围、核对日期。用户提供不等于官方核实；无法核实如实保留状态，不借别处安排补缺。

可追溯、在该事项有权威性且适用的来源若直接支持完整表述，可采用事实修订、忠实摘取、保留条件的简明转述、等价翻译和纠错，记录原文、采用文案、理由、证据和范围；遵守引用限制，不追加逐句批准。证据须覆盖主语、对象、条件、例外、并列范围和行动顺序，多个来源支持若干词句不等于支持AI组合出的因果或步骤。

无直接证据的事实性/行动性新句、扩大范围、改变条件、增加承诺或新正式译名，先给原文、建议、影响和依据缺口，再询问并继续核验；用户同意不代替官方证据。例如来源仅支持一般安全常识，不能为AI新编的“先保护现场再呼救”顺序作证。

## 最小纠错与字段母本

只自动修意义明确的明显错字、非关键标点及布局断行，保留原文、采用文案、理由；不默认同义替换、语气润色。号码、数字/单位、时段、地址/机构专名、否定、条件、范围和行动顺序受保护，不能猜改；语义变化按上节证据原则处理。

母本每项记录`ID / 语言 / 原文 / 采用文案 / 来源 / 状态`，仅含本任务实际字段。状态为用户提供、官方/权威核实、待核验、不适用；排版前逐项核对受保护内容及已提供的地址、资格、费用、开放安排、时限和电话用途。

核验后锁定母本版本，通常仅换行排版。允许的最小纠错或有直接依据的事实/译文纠错可更新版本并回查受影响语言/字形，不重复批准；换行另记布局变化。无依据的语义修改先询问，不能以精简删条件。仅对确实必要而未定的探索字段使用显式占位；正式成稿无虚构值、未解决必要事实或未核验的高影响承诺。

## 校对与责任

文字脚本仅证明副本一致，字形和真实性另查；已用号码、地址、资格、时间逐项核对，不自动拨号或测试紧急号码，不虚构复核人员/签字。输入转写和当前修改对象见[20](20-internal-review-and-current-state.md)。

G4绑定当前文件、来源和适用授权；可选缺项记不适用。有据修订以证据通过文案核验，只选风格不代表事实通过，制作文件不等于授权对外发布。

通用应急号码展示范围按[05](05-style-spec.md#通用应急号码的展示范围)；已授权省略时保存原文、采用文案、原因，不改号码或删专业门诊/任务专线。
