# 阶段卡2：底图

底图 = 不含任何正式文字的完整主题画面，后续所有文字、图标都合成在上面。

## 1. 查参考

分步模式（常规/快速）**不读**未筛选参考池（`assets/reference-extra/`），只用下面的正式库，避免耗时。

- **常规模式**：运行 `python -I scripts/find_reference.py --catalog-layout`，看完返回的全部18张布局巡览页（155份参考），再按文案量、画幅、受众挑2–3张原图打开细看。
- **快速模式**：用结构检索取短名单，例如 `--library posters --query "横版 敬老"` 或 `--density medium --subject-position right`，打开1–2张原图。
- 横版或老年/节日题材优先看 **C组（C01–C08 横版敬老）** 和 **H组（横版16:9）**，构图见[横版与适老版面速查](horizontal-and-elderly-layout.md)；老年受众的信息海报看 **E组**；想要更有表现力的风格看 **D组**；竖版公告优先 P01–P23 与 A/B 组。
- 从参考里只借结构：主体位置、标题位置、留白形状、阅读路线、框景方式；样例的文字、号码、品牌、水印、二维码一律不带入。

## 2. 先定四件事（写进 state.md，后面每个阶段照用）

0. **主体与构图**：按[串联与装饰系统](linking-and-decoration.md)第10节，主题里的人物和动作必须出现；几张底图用不同构图（近景单人、双人互动、俯视……），不要都画群像。


1. **色板**：背景 / 主色 / 辅色 / 强调色 4个HEX，比例约 60% / 25% / 10% / 5%。主题字、正文、图标、装饰全部从这4色及其深浅里取。老年/节日题材可从 `暖米#F7EBD9 朱红#D9452B 菊黄#F2B233 山青#5E7F7A 墨#2B2B2B` 起步，按主题调整。
2. **母题**：从主题里选1个可重复使用的视觉元素（菊花瓣、云纹、风线、屋檐、水滴、叶片……），底图中自然出现，后续用于串联装饰，详见[串联与装饰系统](linking-and-decoration.md)。
3. **空间规划**：每张底图写清：主体位置、标题区、正文区、底部服务区、可以淡化的四角环境。用画布百分比描述，例如“标题区：上方35%”“正文区：左下 40%×30%”。

## 3. 数量与差异

| 模式 | 张数 | 风格 | 主体位置 |
|---|---|---|---|
| 常规 | 3 | 平面简笔、艺术风格化（水彩/国潮/工笔/版画/拼贴任选）、几何平面概括，各1张 | 三张分别偏左、居中、偏右，且至少一张偏上、一张偏下 |
| 快速 | 2 | 从上面三种风格里选两种 | 两张位置不同 |

三种风格的区别要体现在造型和手法上，而不只是换颜色：
- **平面简笔**：简练轮廓、少量平涂，人物/物件/动作一眼可辨，环境疏朗。
- **艺术风格化**：明确的笔触或材质语言，主体和动作清楚；严肃主题保持郑重。
- **几何平面概括**：用圆、半圆、矩形、三角、弧形色块的叠放与正负形概括主体和环境，几何形与主题有关联。

## 4. 画面分量

- 主要人物/建筑/物件约占画布 35%；加上云、地面、植物、四角场景后，图画总量约 45%（接近但不到一半）。
- 四周用与主题相关的环境延展，四角可淡化或做虚影；主体完整、关键动作清楚。
- 留出**连续、干净**的标题区和正文区；底部预留一条完整横带给地址/时间/电话。

## 5. 生成

按[提示词模板](prompt-templates.md)第1–3节逐张写提示词，每个空都填上具体内容；能传参考图时附上入选原图并说明借用哪部分结构。提示词存进 `state.md`。

## 6. 看图与展示

逐张打开检查：风格是否真的不同、主体位置是否符合规划、留白区是否干净连续、有无混入文字/字母/水印。不符合就改提示词定向重生；同一种改法两次无效就换构图或换手法。

把全部底图等比排成一张总览，左侧标 A/B/C，图外简注风格、主体位置、参考编号，然后问用户选哪张（可以合并或要求调整）。等用户明确回答后，把选择写进 `state.md`，进入[阶段卡3](stage-3-title-type.md)。

选定后底图的尺寸、比例、主体轮廓保持锁定；后续只允许局部淡化周边环境。
