# 全量艺术字与强制图标

适用每种语言、完整候选与交付。普通字体仅用于内部初排；用户明确覆盖时记录具体范围，已校验生成资产可复用，不重复生图/批准。字体参考匹配按[24](24-type-generation-references.md)，具体布局按10/21/25。

## 生成范围与字组证据

本任务所有新排入母本文字均须真实生成艺术字：标题、行动、机构名、警示、序号、地址、时段、邮箱、电话/用途标签、紧急号码。普通字体加粗/描边或宣称艺术字体不等于生成。建立完整字组清单，每组关联真实资产/提示和当前可见图层；继承已选主题字笔形/色彩、减少正文装饰，保留清楚字腔、数字、标点。

唯一窄例外：获准使用的原版官方Logo/规范标志不可拆内嵌文字随原资产保留，不重绘艺术化；独立记`original_mark_asset / source / permission / original_integrity / visible_layer`并核对成图。单独机构名/正文/标签、参考截图或普通字体不属于此例外；缺标识不补造。原标识仍查内容、可读性和来源。

地址、时段、邮箱、电话标签/号码分为可独立调节的组，可一次生成有足够透明间隔的素材页后裁组。先逐字校对，再按实际字形边界逐组等比缩放；不压扁或整片缩页脚。小字尤其邮箱、用途、地址、时段和分机独立核对，不能由大标题通过推定。

容量不足先调分组、断行、栏宽/位置/层级；字形错误定向修复。连续2轮同策略失败改拆组/生成策略，仍失败留失败/未验证，不默许普通字体替代或虚报完成。

主题字按11将语义辅助写入同次实际生成，保留标题文字与符号/线条的完整组合，外置元素可为关联独立层；素材页分组裁切、透明边界处理、缩放及合成均复查细线/离散符号是否遗漏。正文继承只按21保留笔形气质，不机械复制标题装饰；标题辅助不替代下方的地址、时间、电话等功能图标。提示中写过而资产里没有，不能记为已经生成或成图通过。

## 资产复用与生成范围

同语言、同文案、同字形风格的已核对主题字、正文、小标题与图标可跨三款完整排版复用；只改位置/等比大小不重新生成同字组，重新缩放/合成仍做第二次渲染检查。真实文字、语言、笔形或色彩方案变化时，重生成或定向编辑变更资产并核对。

复用前核对完整母本字组库存及生成证据/版本；当前完整合览已齐备时直接合成，不再因进入“艺术化”阶段重生全文。历史方向试样或局部素材不证明齐备，只补缺失/失效组。

## N6a图标硬约束

正文派生时按信息组取得/复用素材；完整排版容量预检前核对库存，只补缺失/失效项，初排实际添加，合成/导出查实际入图。图标与文字是独立环节，生成文字不代表图标已入图。

|已有类别|普通辅助图标|
|---|---|

每张至少一处有意义图标，各适用类别至少一处实际入图；同类邻近组可共用，不机械逐行增加，未提供字段不补造，数量随任务类别/布局而定。图标不替代文字/号码，不错用相反语义、官方徽标或自由重绘安全标志。来源顺序/许可按[06](06-icon-sourcing.md)，尺寸/风格/语义配色按[07](07-icon-style-matching.md)；来源失败继续寻找/原创，不退成零图标版。
