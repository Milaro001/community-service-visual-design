# 精修颜色比较与海报可读性审查

配色精修在整体版式已选、全量艺术字及图标已合成后执行。下方像素/视觉检查也用于11模块主题字展示前的轻量叠放，只检查当前标题/底图，不推定完整海报通过或启动精修A/B；缺实际像素输入则该线unknown，继续真实视觉检查。当前设计偏好依[25模块](25-mandatory-design-preferences.md)，像素、视觉和用户配色选择分别记状态；数值通过不等于实际阅读已确认。

## N7b 精修颜色版本与用户选择

首次配色探索制作A当前配色、B字体更鲜艳两张真实成图；锁定母本、字形、底图、图标、画布与版式。逐组调整文字饱和度／填充，不提高整张海报饱和度冒充文字改色，不把高饱和等同高明度或逐行乱换色。艺术字沿用实际生成资产／编辑规则，图标按许可处理，不用普通字体重排。

两版各语言均完成下方像素及视觉审查，低对比先在授权范围内定向修复。依[22模块](22-selection-overview.md)展示左侧编号实际总览，再集中问A/B或调整意见；可与成图审阅合并，不重选底图／主题字／版式或逐句批准。真实答复如“b”直接绑定当前B，不重问；推荐／沉默不算选择。无实际B图或编辑能力则记未完成，不假称已确认。

已有明确色值／配色选择或授权局部改色时，直接在该范围制作、展示最新实图，不重开A/B；用户明确要鲜艳则直接做B，已确认同版本不重复询问。受影响项仍审查，比较只在用户要求范围内展开。

## 语义图标、统一数字与舒适度精修

普通图标语义配色及规范／品牌色依[07模块](07-icon-style-matching.md)。时间、日期、普通咨询电话及普通数字用同一协调强调色，区别正文与标题，冒号／连字符／区间线同色，用途标签可保持正文色。完整保留值、格式和顺序；紧急号码或规范安全色可独立，记例外。用户明确仅改某一信息组（如咨询电话）时记录本项目局部色彩例外，直接按该范围执行，不扩改其他数字或追加确认。艺术字明暗变化不冒称全像素精确同色。

“鲜艳”和“更深”是不同目标。用户反馈暗沉时，可在授权范围提高主填充明度、减暗影／强高光，保持字腔并查当前局部对比；不提亮整张背景或把所有字变淡。图文处理和承托／横线／地点框分别依25及[10模块](10-position-and-whitespace.md)，真人阅读反馈不能被数值驳回。

## 两条独立的检查线

### 实际像素与底图局部对比

- 使用最终导出、同尺寸精确字后背景、最终注册RGBA文字／图标资产及位置；不以全幅平均色或几组HEX判全图通过。
- 逐组报实心识别笔画的最小对比、1%分位、中位值、低于阈值比例及最差坐标，并说明抗锯齿／半透明遗漏。正文屏幕项目最低4.5:1，重点信息目标7:1；图标按语义设阈值，不给装饰贴统一WCAG认证。
- 仅有扁平图或不可靠掩膜时，用可用OCR／视觉定位找问题，不能精确还原字后背景；OCR未运行记未运行，中文／邮箱／数字仍逐字对母本。
- [像素脚本](../scripts/audit_poster_readability.py)依Pillow／NumPy读取分层数据，无OCR／模型；缺输入、透明字无实心像素或图层不匹配保留unknown，不自动pass。

### 实际视觉可读性与色彩舒适度

打开整图、目标显示尺寸／缩略图及正文／底部局部，检查暗沉、图底融合、字腔粘连、笔画密度及地址／日期／邮箱／号码辨识。保存“问题→修复→当前文件／版本证据→状态”，不只填总分。

用户说太暗或吃力，当前视觉状态保持未通过／待修复；制作可见改版，不能用像素达标反驳，AI不冒称真人距离或印刷测试。

## 精修改动范围

修改前绑定前版，列明可改图层／属性／区域及保持项。仅改颜色时，字形、位置、大小、断行、背景及其他层保持；范围外容量／留白问题记建议或未解决项，不自动重排／放大。已授权布局调整时才可依[26模块](26-linebreak-and-whitespace.md)减碎行、调间距和利用栏宽。

编辑后看整图，按母本核对全部可见文字及前版，查错字、标点、换行、意外字形／宽高变化和旧位置残留；越界改动先修复。整图再生成可能改字，须重新逐组校对全部字形，重点为机构、时段、条件、号码用途、电话／分机、邮箱、地址；只编辑局部资产且其余层可验证未变时，复用其检查记录，详细字形／对比／容量／语言测量仅回查变化及依赖项。错组定向修复并合成，不换普通字体；最终整图仍打开，证据依[20模块](20-internal-review-and-current-state.md)。

## 配色编辑后的文案回归与最终交付

比较图来自最新导出，完整显示画面／底部，版本号放图外；每语每版独立审查。用户选择只证明当前配色／成图选择，不证明事实、真人距离或印刷认证。新问题实质影响成图时展示修复影响。

正式交付用所选最新已审查文件，旧版留历史；记录语言、版本、选择证据、像素尺寸、图标许可、艺术字覆盖及未验证项。直接复制时核验与所选文件一致；重渲染、换背景、缩放或修改资产后回查受影响项。

## 脚本输入与输出

JSON路径相对该JSON目录。`poster`和`background`须在实际显示底色上合成为不透明图，透明／调色板透明输入会被拒绝，不自动补白。`background`是所有待测资产下方的精确合成背景，包括实际承托形状、背景编辑及前后图层效果，排除清单中的待测文字／图标；不能让图标与自身比对。`placed_asset`用最终尺寸RGBA层，`bbox`与实际尺寸一致。待测层叠放而无法共用正确背景时，另备分层输入或记unknown，不声称自动还原。

```json
{
  "poster": "poster.png",
  "background": "background-without-audited-assets.png",
  "expected_group_ids": ["address", "location-icon"],
  "threshold": 4.5,
  "groups": [
    {"id": "address", "kind": "text", "bbox": [100, 500, 800, 620], "placed_asset": "address-final-size.png"},
    {"id": "location-icon", "kind": "icon", "threshold": 3.0, "bbox": [50, 500, 90, 540], "placed_asset": "location-final-size.png"}
  ]
}
```

运行`python3 scripts/audit_poster_readability.py manifest.json --out-dir review/`，依赖见[requirements](../scripts/requirements-pixel-audit.txt)。首次运行若默认Python缺依赖，按[12](12-platform-compatibility.md)选择已有可用解释器并在本任务记录/复用路径；不重复用同一缺依赖环境重试。`--help`不加载像素依赖，实际缺依赖返回unknown/退出2，不生成假报告。退出码按`audit_status`：0=提交组像素及清单完整性通过，1=失败，2=未验证／输入无效。`pixel_contrast_status`只代表提交组；`expected_group_ids`须为应审完整清单，缺清单unknown、遗漏／多组fail，不能只测一组称全图通过。

脚本测足够不透明像素，不自动区分识别笔画、剪纸镶嵌、描边或装饰。人工另记识别／装饰证据，保留原低对比结果；不能把装饰失败直接等同不可读，也不能删除真正笔画失败。多色图标分别查外形与外部背景、内部符号与承托色；白符号不只与被遮住的照片比。无可靠分区／图层关系记unknown，不删像素凑通过，脚本无自动分区。

输出逐组JSON、低对比标记图及≤1600px宽预览，不代表OCR、字体完整、用户选择、真人距离或印刷认证。每语／版本分别运行；更换资产、背景、缩放、位置或导出后回归受影响项。

## 检索来源与能力边界

本模块与像素脚本为面向静态海报自行编写，未捆绑／执行上游实现：参考[contrast-check](https://github.com/pascalorg/skills/blob/main/contrast-check/SKILL.md)的颜色对计算、[MIT accessibility-audit](https://github.com/humbleteam/accessibility-audit/blob/main/SKILL.md)的最差区域／证据报告、[NVlabs海报原则](https://github.com/NVlabs/Skill2Env/blob/main/SkillHub/skills/alterlab-pptx-posters/references/poster_design_principles.md)的层级尺度及[W3C文字图像对比解释](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。网页大字3:1或打印字号不直接套本技能；未确认能自动完成中文全量OCR、最差背景对比及审美认证的现成skill，说明文件不赋予这些能力。
