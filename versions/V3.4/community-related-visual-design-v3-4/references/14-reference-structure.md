# 实例结构提取与构图参考卡

信息分组/构图时复用已有适用提取记录；缺方法或出现适配问题才读本文件。来源需核对时补[16](16-layout-sources.md)，当前设计偏好由[25](25-mandatory-design-preferences.md)维护。

## 用户指定的优先版式参考

按[23](23-priority-layout-references.md)打开骨架并定位近似具体子图，记录文件、区域/行列，提取字形比例、分行/行距、分散程度、轴线、分组与阅读路径；适配完整母本和已选底图，不照搬稀疏小字/黑白配色。

## 实例适配记录

只为实际用于设计的入选实例建立提取记录；全库巡览仅在20当前状态记录版本、巡览页和未读项，不为147份图逐份重建详细映射：`reference_id / source / viewed / reference_role / regions / reading_order / alignment_axes / grouping / whitespace / density / background_complexity / protected_subject / field_mapping / reuse / adaptation / excluded`。regions使用0–1相对坐标，属于结构描述，最终按实际文字重新度量。

筛选优先级：当前内容语义和受众可读性→信息密度与最长语言→已选底图连续留白与主体保护→已选主题字方向→画布/渠道→视觉气质。主题相同但密度不匹配的实例可以只作风格参考。只取结构不抠图，不复制原文本、机构、号码、水印、商标和未获许可字体。

选择结构需解释：本次哪组信息对应参考哪一区域；哪里必须增高/拓宽；阅读顺序是否改变；在当前底图上是否覆盖主体。不能只写“参考瑞士风”“采用九宫格”而不绑定具体分组和轴线。多参考可分别承担风格与结构；一个候选应有可解释的主组织系统，不把多个模板的装饰全部堆叠。

## 结构卡（内部筛选，最终仍供用户选完整海报）

| 卡 | 适配内容 | 核心关系 | 容量风险与调整 |
|---|---|---|---|
| 顶部标题堆叠 | 中密度公告、活动信息 | 标题→短说明→正文→服务入口沿共同轴线 | 大标题易挤正文，高密度先重排，不自动降低用户指定标题目标，底部留完整号码区 |
| 编辑分栏 | 高密度、多组服务说明 | 标题统领，正文沿2–3栏顺序，相关组靠近 | 不把句子任意拆到下一栏；实测中文行长与较长英文，避免窄栏碎句 |
| 水平分区 | 标题/主体/正文上下分明 | 按语义分成上下区域，由留白分隔 | 先用无框文字分区，按25减弱周边环境，必要时才按10承托；保持主图尺度/中心与完整信息 |
| 侧边锚点 | 竖向主题字、主体偏一侧 | 侧标题锚定，正文在另一侧连续留白 | 长正文不能随标题逐字竖排；数字和英文词组保持完整 |
| 步骤序列 | 至少3项有顺序的步骤或日程 | 序号、短标题、完整说明沿轴线递进 | 原文顺序与条件保留；不添加未经提供的救助行动 |
| 模块网格 | 多个并列类别/服务点 | 同级组共享字号、宽度及间距，标签靠近内容 | 模块是几何分组，不自动画卡片；行数不同允许增高，不强凑等高 |
| 居中主体 | 低密度、一句话与少量信息 | 一个视觉重心，配套文字在周围连续留白 | 不把长文塞主体四周；多个竞争焦点时换结构 |
| 下方或沿边标题 | 主体/留白适合底置或沿边 | 标题锚点与服务入口分离，正文有明确阅读路径 | 不机械套上标题时的左右底部电话规则，按真实空间保持用途和数字完整 |

结构可组合，例如顶部标题＋编辑分栏，但层级和阅读路径需统一。三种候选必须有实际结构差异并适配同底图，不强行使用全部卡。

## 层级与空间提取原则

同级组使用相同视觉待遇；组内距离小于组间距离。标题与其下属内容更接近，标签与值不分离。视觉角色默认3–4种，以字重、空间与位置共同承载；颜色只强化，不单独表达关键分类。具体字号从受众正文字号向外推，不强套黄金比。缩略图/灰度预览用于发现竞争和只靠颜色的问题，不能替代文字准确性检查。

对齐按结构选择共同轴线、居中轴或刻意错落；网格承担组织，不是成品装饰。可见墨迹与盒边不同，艺术位图需按非透明字形边缘评估。相等边距、双色、≤5%强调色、两行页脚属于特定风格选项；只有当前选定该风格且不违反内容、可读性和规范色时启用，不放入通用硬闸门。
