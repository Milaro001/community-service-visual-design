# 提示词模板

写任何生图提示词都从这里取模板，**每个 {} 都填具体内容**，不留空、不写“有趣一点”这类模糊词。中文描述内容，英文关键词描述风格（生图模型对英文风格词更敏感）。提示词存进 `state.md`。

## 1. 底图通用模板

```
【用途】社区海报底图，画面中不出现任何文字。
【画幅】{竖版3:4，3200×4000 | 横版16:9，3840×2160}
【主题情节】{谁}在{做什么}，地点{哪里}，情绪{温暖/安心/郑重/欢快}
【风格】{风格预设名}：{从第2节复制该预设的关键词}
【主体】{主体描述}位于画面{左/中/右}{上/中/下}部，宽度约占画面{40–50}%，完整不出画，{动作/朝向}
【环境】{2–3个主题环境元素}从{两侧/四角}向外延展并逐渐淡出；四角用{淡化场景/雾气/虚影}收边
【留白】{标题区，如：上方35%}为干净的{底色}平涂或薄雾区域；{正文区，如：左下40%×30%}为低细节区域；底部{12}%为干净横带
【色板】背景{HEX}，主色{HEX}，辅色{HEX}，强调色{HEX}；全图只用这几种颜色及其深浅
【光线视角】{平视/略俯视}，{柔和侧光/顶光}，{无/轻微}阴影
【母题】画面中自然出现{母题元素}，形态清楚，便于后续复用
【串联】{底图中的路径/河流/云带/视线}从主体延伸向{正文区}，形成视觉引导线
【排除】no text, no letters, no numbers, no Chinese characters, no calligraphy, no logo, no watermark, no QR code, no frame, no border, no UI elements, no icons; 留白区内不放主体和复杂纹理
```

## 2. 风格预设

| 预设 | 关键词（复制进【风格】） | 适合 |
|---|---|---|
| 平面简笔 | flat vector illustration, clean simple outlines, 2–3 tone flat fills, minimal texture, generous negative space | 公告、服务指引 |
| 扁平插画·暖调 | flat illustration with soft gradients, layered paper-cut mountains, ribbon-like clouds, rounded friendly characters | 敬老活动、邻里活动（参考 C07） |
| 国潮水彩 | Chinese watercolor and gouache, soft wet edges, rice paper texture, layered misty mountains, warm sunset glow | 敬老、节日、文化（参考 C01 C03 C05 C08） |
| 金色工笔山水 | gongbi fine-line Chinese landscape painting, gold and ochre tones, layered peaks in mist, delicate pine trees and pavilions | 隆重节日（参考 C04） |
| 蓝调水墨 | blue ink wash landscape, misty mountains, calm reflective water, airy white space | 思亲、宁静主题（参考 C02） |
| 水彩静物 | watercolor still life, warm light, textured linen tablecloth, soft shadows | 饮食、民俗（参考 C06） |
| 版画 | linocut print texture, bold carved shapes, limited 3-color palette, visible paper grain | 文化、倡议 |
| 拼贴 | paper collage, torn paper edges, layered textures, cut-out shapes | 青年、环保、创意活动 |
| 几何构成 | geometric flat composition, circles semicircles rectangles triangles, overlapping color blocks, positive-negative space, Swiss poster style | 几何方向底图 |
| 2.5D等距 | isometric 2.5D illustration, soft gradients, clean rounded shapes | 政务、数字服务（参考 A组政务门牌） |

常规模式三张底图分别取：平面简笔类（平面简笔/扁平插画）、艺术风格化类（水彩/工笔/水墨/版画/拼贴）、几何构成各一。

## 3. 横版敬老/重阳预设（从 C01–C08 归纳）

**常用元素（可选，不是必须）**：老人相携背影（一人拄杖），走在山路/水边/小径上；红日或满月；菊花与枫叶前景框景；层叠远山和云雾；1–3只鹤或飞鸟。

**色板起点**：暖米#F7EBD9 / 朱红#D9452B / 菊黄#F2B233 / 山青#5E7F7A / 墨#2B2B2B（蓝调方案：浅青白#EEF4F7 / 靛蓝#1F4E8C / 朱红#D9452B）

**四种构图**：

| 构图 | 主体 | 标题区 | 参考 |
|---|---|---|---|
| A 主体右·标题左上 | 老人站在右侧山崖，宽约25% | 左侧上方2/3雾气留白 | C01 |
| B 中轴竖排标题 | 老人在底部中央或右下 | 画面中轴，红日圆在标题后方 | C03 C08 |
| C 主体左·标题右 | 老人剪影在左下 | 右侧中部 | C05 C06 |
| D 标题上中·底部服务条 | 老人在中下部 | 上方中部；底部留白横带放服务信息 | C02 C07 |

**示例（构图A，国潮水彩）**：
```
【用途】社区重阳敬老活动海报底图，画面中不出现任何文字。
【画幅】横版16:9，3840×2160
【主题情节】一对老人相携登高远望，一人拄杖，站在秋日山崖小路上，情绪温暖安宁
【风格】国潮水彩：Chinese watercolor and gouache, soft wet edges, rice paper texture, layered misty mountains, warm sunset glow
【主体】老人背影位于画面右侧中部，宽度约占画面12%，所在山崖与小路宽约30%，完整不出画，面朝左上远方
【环境】金黄菊花与红枫叶从左下角和右下角向内框景；远山三层渐淡；右上方一轮朱红落日，两只白鹤飞向左方
【留白】左侧上方55%×55%为浅米色薄雾平涂区域；底部10%为浅色云雾横带
【色板】背景#F7EBD9，主色#D9452B，辅色#F2B233，强调色#5E7F7A；全图只用这几种颜色及其深浅
【光线视角】略俯视，柔和逆光，轻微阴影
【母题】画面中自然出现卷曲的祥云纹样和菊花，形态清楚
【串联】一条蜿蜒的金色小河从右侧山脚流向左下，形成视觉引导线
【排除】no text, no letters, no numbers, no Chinese characters, no calligraphy, no seal, no logo, no watermark, no frame, no border; 左上留白区内不放山峰和鹤
```

## 4. 主题字模板

```
【用途】海报主标题艺术字，纯白背景（或透明背景），四周留足空白便于抠图
【文字】“{准确标题}”，逐字为：{字1}／{字2}／…；排法：{横排一行 | 两行，第一行“…”第二行“…” | 竖排一列，从上到下 | 竖排两列，左列“…”右列“…”}
【笔形】{例：浓墨行草，起笔重收笔轻，带飞白，末笔长弧拖尾}，参考{TGxx}的{具体字例特征}
【组合】{左齐右参差 | 两行错位、第二行横画外伸 | 大字配细宋体小字 | 竖排主字旁配小号竖排副题}
【语义辅助】{元素}位于{字组的哪一侧/哪个空隙}，表示“{关键词}”，大小约为字高的{1/4}，颜色{HEX}
【颜色】主字{HEX}，辅助元素{HEX}
【排除】no background scene, no extra characters, no wrong characters, no frame behind the title; 字腔清楚不粘连，笔画不缺失
```

## 7. 局部修改模板

```
只修改{具体区域，如：右下角电话号码这一行}：{具体改动，如：颜色改为#D9452B}。
画面其余所有内容、文字、位置、大小、颜色保持完全不变。
```

## 8. 通用排除词

`no text, no letters, no numbers, no watermark, no logo, no QR code, no frame, no border, no UI elements, no extra characters, no distorted hands, no cropped subject`

底图里需要保留的留白区，用“{区域}内不放{主体/复杂纹理}”的写法单独说明。

## 9. 整图模板（一键出图）

一键出图用这一节。原则（来自[网络提示词参考库](web-prompt-library.md)）：**上图文字全部用引号逐条列出；版面按区域写清；风格词只写一组，不堆形容词；只要一张成品。** 中文写内容，英文写风格。

```
【用途】一张完整的社区{活动/通知/指引}海报成品，{竖版3:4 | 横版16:9}，面向{受众，如：社区老年居民}。只输出一张成品海报，不要样机、相框、拼板或多个变体。

【风格】{从一键风格预设复制关键词}
【核心画面】{受众人物＋核心事物＋动作，例如：一位奶奶举着手机自拍开怀大笑；构图按串联与装饰系统第10节换着用，不要每次都是群像，也不要只画物件不画人}，位于画面{位置}，约占画面{40–50}%。
【字图关系】标题、插画、图标、数字和装饰线用同一种笔触画出，共用纸纹和光线；图文共享一条阅读路线，文字不游离在画面之外。
  - 标题与主体穿插：{例如：手机线框从标题后方穿出 / 主体人物一角压住标题末字}
  - 图标当容器：{例如：地点写在房子线框里；日期写在日历图标里；电话号码紧贴电话图标}
  - 大数字图形化：{例如：日期“10.20”做成画面第二大的元素；“50+”配人群小图标}
  - 贴纸标注：{例如：右上角一个略倾斜的“开课啦！”贴纸}
  - 动线：{例如：一条虚线从插画出发，依次经过日期、地点、电话}
  - 关键词标注：{例如：“免费”“一对一”加荧光笔底色或手绘下划线}

【版面意图】（只给方向，不画格子）
  标题占据画面{上部/左侧}一大片，字可以很大、可以压到插画上；主体插画在{位置}；
  阅读从标题 → {大日期} → {地点/电话} → {提示}，用{虚线/小路/飘带}串起来；
  各信息组像散落在画面里的手写便签、标签、气泡，大小不一、角度略有不同，不要排成整齐的表格或等宽卡片；
  画面要饱满，字要大方，不要把文字缩在小框里。
【正文字体】正文、小标题、数字都用与主标题同一支笔的{手写毛笔字/马克笔字/圆润手绘字/书法小楷}，同一套颜色，不使用电脑标准字体的观感；字组可以倾斜（±8°以内）、沿弧线、写在物件上（门框、日历、黑板、手机屏、横幅）。

【必须准确显示的文字】（一字不改，除此之外不要出现任何文字）
  主标题："{…}"，{字体：粗壮手写毛笔字/粗黑体/行书}，颜色{HEX}，画面最大
  副标题："{…}"，{字体}，颜色{HEX}
  小标题："{活动时间}" "{活动地点}"……，放在{色块标签/图标旁}
  日期："{10.20}"，{强调色HEX}，特大号
  时段："{上午9:30—11:00}"
  地点："{二楼活动室}"，写在{房子线框图标}内
  电话："{8888-1234}"，紧贴电话图标，{强调色HEX}，大号
  主办："{主办单位：幸福社区居委会}"，小号
  提示："{课堂免费，不推销手机和套餐；现场有志愿者一对一辅导。}"，关键词“{免费}”“{一对一}”加下划线
  （逐条列出母本中的每一条，数字逐位核对）

【排布约束】所有文字和插画、图标在这一张图里一起设计好：正文用中等字号，明显小于标题和小标题；任何文字都不压住图标、插画主体和装饰，字组与图标之间留出空隙。
【色板】背景{HEX}，主色{HEX}，辅色{HEX}，强调色{HEX}（强调色只用于数字、关键词、贴纸）；全图只用这几种颜色及其深浅。
【可读性】正文与底色高对比；日期、地点、电话明显大于正文；不使用细体和浅灰小字；文字不压在复杂纹理上。{老年受众时加：large high-contrast text for elderly readers}
【安全边距】所有文字距画面边缘至少5%。
【排除】no pseudo-text, no placeholder text, no extra slogan, no lorem ipsum, no fake QR code, no logo, no watermark, no mockup frame, no split panels; 不要出现上面列出之外的任何文字或数字。
```

写完自查：①母本每一条都在【必须准确显示的文字】里；②号码、日期逐位一致；③字图关系至少写了3项；④只有一组风格词；⑤没有写成死分区表格。

**改错字的局部编辑提示词**（配合蒙版，只涂错字区域）：
```
只修改蒙版区域：把这里的文字改为"{正确文字}"，字体气质、粗细、颜色{HEX}、大小和位置与周围原文字保持一致。蒙版外的所有内容保持完全不变。
```

## 10. 把文字画进已有画面（分步模式第4阶段；一键出图不用）

```
以这张图为基础，在{留好的位置，如：右下方的撕纸便签 / 中部黑板 / 底部横幅}上写入以下文字，其余画面完全不变。
文字用与图中主标题同一支笔的{手写字风格}，颜色{正文HEX}，关键词{"免费""一对一"}用{强调色HEX}并加{下划线/圈注}；
字组顺着{便签/横幅}的形状略微倾斜，字大而清楚，笔画不粘连，与底色对比强。
必须准确显示（一字不改，除此之外不写任何字）：
  "{第1行}"
  "{第2行}"
  "{第3行}"
no extra text, no pseudo-text, no garbled characters.
```
一次最多写约60字；更多时分区域分几次编辑。写完立刻做一键出图卡4.2的盲读、对照、清晰度检查。
