# 三张底图：风格探索与主体位置覆盖

每轮新底图默认实际生成3张；用户当次明确覆盖数量／风格／位置或跳过探索时执行，已有底图／局部精修不重新凑3张。此规则只管N4，不改变各语言主题字5款（3横＋2竖）、标题正文强制合览确认、完整版式默认3款或精修配色。

## 三张的风格组成

下列三方向各1张，不一图计两类；同一主题分别用轮廓平涂、明确艺术笔触/材质、几何正负形构成表达，造型与主题内容都须真实不同，不只换色／滤镜。课程F1–F5不是数量要求，不另补第4/5张。

| 必含方向 | 画面与区别 |
| --- | --- |
| 平面简笔构成 | 简练轮廓、少量平涂、可辨人物／物件／动作及疏朗环境；以形象轮廓为主，不是线框、散列图标或角落小插画 |
| 艺术风格化 | 选明确语境适用的彩墨、水粉／粉彩、版画或拼贴等语言，用笔势、材质、形体概括及构图表达；主体／动作可辨，严肃内容不戏谑 |
| 几何元素平面概括 | 圆、半圆、矩形、三角、弧／色块概括主体、动作及环境，用叠放、切分、正负形构成；几何与主题有可解释关系，不做写实立体、UI卡片、教学网格或空容器 |

实际查P01–P23及A/B实例，按[28模块](28-background-composition-planning.md)记录具体原图／子图、借用结构／语言及排除项，转换为本次主题与文案空间，不复制品牌／样例事实。无足够相近风格图时，记录可借部分与本次创作方法，不宣称找到或传入不存在的图。

## 主体布局：左、中、右与上、下变化

整组实际覆盖主体居左、居中、居右各至少1张，另有至少1张偏上、1张偏下；不要求遍历九宫格，也不固定右下。风格与位置不永久绑定，依据参考、视线／动作及文字容量安排，居中仍须有可读文字区。

横向按主体视觉重心／大面积分布、纵向按锚点判定，每图只记一个横向主类别，不能模糊一图充左／中两类；角落环境不作主体。可记录归一化范围／中心及目视依据，不冒充像素分割。主体／环境分量、四角延展和文字尺度依[25模块](25-mandatory-design-preferences.md)，简笔／几何同样适用，不能缩成角落图凑覆盖或编造地图、服务点、机构、规范标志、操作事实。

## 生成前规划与成图修复

三行规划及实际提示依28模块。逐张开图检查风格区别、三个方向、主题、位置／尺度、环境、保护对象及文字空间；缺图、方向或位置覆盖先补具体候选。连续2轮同策略无效换构图／方法并记录；仍未完成如实说明，继续无依赖工作，不把较少／重复图片报为3张完成。
