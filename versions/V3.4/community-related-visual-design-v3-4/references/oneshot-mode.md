# 一键出图卡：整图生成 + 局部修字

一键出图 = 标题、插画、图标、数字、装饰线和正文**在同一张图里一次画出来**，再逐字核对、局部修字。不让用户中途选底图、主题字、排版；只在开头问一次风格，在出图后问一次交付格式。

为什么整图生成：同一支“笔”画出的字、图标、插画共用线质、纸纹和光影，可以互相穿插、遮挡、包含，天然有呼应；分开生成再剪贴的字只能是“贴上去的”。

## 0. 什么时候走一键出图

阶段卡1拆完资料、写好母本后，运行：

```
python -I scripts/count_copy.py state.md        # 或 --text "直接粘贴的上图文案"
```

| 用户是否指定模式 | 上图文案计数 | 走哪条路 |
|---|---|---|
| 用户说了常规/快速/一步步来/想看每一步 | 任意 | 按用户说的走阶段卡2–5 |
| 没说 | ≤100 | **直接一键出图**，不问模式 |
| 没说 | 101–160 | 一键出图，仍然一次出完；资料允许时先精简文案（第6节） |
| 没说 | >160 | 问一次：混合一键 / 快速 / 常规，推荐快速 |

计数口径：只数**上图文案**（母本），不是整份PDF；汉字和中文标点不计标点，汉字每字1，数字和拉丁字母每2个算1（脚本已实现）。主标题也算在内。

## 1. 唯一一次开头提问（合并成一条消息）

1. **风格**：按 SKILL.md“必经一步”运行 `scripts/pick_styles.py` 抽选项，**用选择题工具让用户点选**（可在“其他”里写“你定”“换一批”或自己描述）。用户说“你定”时，从这5种里挑最贴主题的一种。
2. **方向**：用户没说时默认竖版；材料提到展板、电子屏、公众号头图、横幅时默认横版16:9，在消息里写明“按横版做，不对请告诉我”。
3. **缺失的必要事实**（日期、地点、电话等，只在缺失或冲突时问）。

不问：尺寸精度、是否印刷、是否要源文件——这些放到出图之后（第5节）。

**风格问题不能跳过**：即使事实齐全，也必须先问风格并等回答（问法原文见 SKILL.md“必经一步”）。只有用户这次已经明确选了五种之一或说“你定”时才不问。

## 2. 找参考（3分钟内）

1. 本地库按风格和画幅检索：
   `python -I scripts/find_reference.py --library posters --query "<风格词> <题材词>" --limit 4`
   横版加 `横版`；老年题材加 `敬老` 或 `养老`。D组（风格参考，可用 `--query "手绘暖调插画"` 等风格名检索）、H组（横版16:9）、E组（适老信息海报）是一键模式的首选库；整图提示词写法另见 `assets/web-prompt-examples/` 和[网络提示词参考库](web-prompt-library.md)。
2. **未筛选参考池（只有一键出图读，分步模式不读）**：运行 `python -P scripts/extra_refs.py --domain <主题编号> --grade A`（池子在 `assets/reference-extra/`，或 `agents/local-resources.json` 的 `extra_reference_dir`）。池子自带登记表时按主题分类：D01政务证照 D02社保救助 D03养老为老 D04医疗健康 D05育儿青少年 D06就业社保 D07住房物业 D08环境环卫 D09安全应急 D10法律调解 D11文化体育 D12志愿公益 D13邻里自治 D14特殊群体 D15商业便民；先看本主题，不够再看1个相近主题，不要一次看全部200张。脚本把图排成带编号的巡览页并缓存。**只看巡览页缩略图**，按所选风格挑2–3张，再用 `--id D03_05` 查原图打开细看。池子没经过筛选、质量参差：只借风格、配色、字图关系，看不上就不用，不强求；返回 `empty` 时跳过。
3. 用户这次另给的文件夹或图片一并看。
4. 能联网时可以再搜1–2张同风格作品，只看不下载进成品；本地库已够时跳过。
5. 每张入选参考写一句“借什么”：构图 / 标题组合 / 字图交互手法 / 文字怎么“放飞” / 配色。不借文字、品牌、人物肖像和水印。
6. 生图工具支持参考图输入时，附1–2张参考图并写明“只参考风格与版面结构，不复制其中文字和图形”。

## 3. 写整图提示词

用[提示词模板](prompt-templates.md)第9节（整图模板）。写之前先在 `state.md` 定下：

- **版面意图**（不是格子表）：只说清“标题在哪一带、主体在哪、阅读从哪到哪、电话日期大概落在哪”，其余交给模型自由组织；不要写成“区域1/区域2/区域3”的死分区，那样出图会像表格、字被框得很小很规矩。横版和老年受众可参考[横版与适老版面速查](horizontal-and-elderly-layout.md)；
- **色板**：背景、主色、辅色、强调色4个HEX；强调色优先取主色的**互补或对比色**（如橙配绿、朱红配青），只用在数字、关键词和贴纸上；
- **母题**：1个，出现在标题装饰、分隔线、编号底形、图标底座中至少3处；
- **主体**：按[串联与装饰系统](linking-and-decoration.md)第10节——主题里的人物（如老年人）和他们在做的事必须画出来，变化的是构图和镜头；
- **字少时**：按第11节做至少3处语义图形化（标签词换图标、承托形状跟词义走）；
- **字图交互**：从[串联与装饰系统](linking-and-decoration.md)第7节挑**至少3种**写进提示词（图标当容器、大数字图形化、标题与主体穿插、贴纸标注、虚线动线、关键词标注）；
- 资料允许精简时（阶段卡1第3节），先把长句缩短再写提示词——字越短，整图出字越准、版面越松。
- **全部上图文案逐条列出**，每条写明角色（主标题/副标题/小标题/正文/日期/电话……）、位置、大小档位、颜色，文字用「」包住，**一字不改**；
- 层级至少4级：主标题 → 关键信息大数字/小标题 → 正文 → 标签注释。
- **文字放开**：按[串联与装饰系统](linking-and-decoration.md)第9节写进提示词——正文也用与标题同一支笔的手写/艺术字，字组可以倾斜、错落、沿弧线、塞进图形、大小跳跃，信息组之间不对齐成表格。

提示词写完自查：母本里每一条都出现在提示词里；号码、日期逐位一致；没有写进母本之外的文字。

## 4. 生成与审查

### 4.1 生成

- 尺寸：工具支持自定义尺寸时，竖版用接近 A3 的比例（如 2480×3508 或工具上限内同比例），横版用 16:9（如 3840×2160 或 1920×1080）；只支持固定档位时选最接近的（竖 1024×1536、横 1536×1024），交付阶段再扩边适配。
- 数量：默认**同时生成2张**（同一提示词，或构图分区略有不同），按4.2审查后**自动挑一张**（先比文字正确率，再比可读性和整体观感），不让用户选；另一张保留在 `state.md`，用户想看再给。工具只能串行且很慢时生成1张。
- 提示词、种子/版本、文件路径写进 `state.md`。

### 4.2 审查（自己做，不需要第二个agent）

**第一步：盲读。** 先不看母本，把图上看到的每一行字**逐字抄出来**（看不清的字记为□）。原因：先看母本再看图，容易“看见”本该在那里的字，漏掉错字。

**第二步：对照。** 把盲读结果和母本逐条比：

| 必须完全一致（错一个就修） | 次要（明显时才修） |
|---|---|
| 电话、日期、时段、门牌、金额、人数等所有数字 | 标点、空格 |
| 地址、机构名、活动名 | 断行位置 |
| 否定词和条件（“不”“免费”“仅限”“需携带”） | 字距 |
| 主标题每个字 | |

同时检查：有没有母本之外的**多余文字、伪汉字、乱码、假二维码、假logo**；有没有漏掉的信息组。

**第三步：清晰度。** 放大看每一组字：有没有**模糊、糊成一团、笔画粘连或缺笔、字压在纹理上认不出**；缩到手机屏宽度时电话和日期是否还能读。

另外检查一项：文字有没有压住图标或插画主体。

审查只做这几步；配色和构图不再逐项审，明显难看时再说。

### 4.3 修字（只动错的那一块）

1. **局部重绘**：工具支持蒙版编辑/局部修改时，只框错字所在的那一行或那个字组，用[提示词模板](prompt-templates.md)第7节，写明正确文字、字体气质、颜色、大小与原来一致，其余不变。
2. **同一处重绘2次仍错**：把这一组字的蒙版扩大一圈、提示词里把字逐个拆开写（“依次是：二／楼／活／动／室”），再重画1次；仍错时才用真实字体贴补（`python -P scripts/patch_text.py`，只适合平涂色或纸纹底），并在交付说明里写明“此处为字体贴补，风格与周围不完全一致”。
3. **错误超过3处或主标题错字**：不逐个修，整张重生（可以把错的字在提示词里单独强调，例如“注意：是‘龄’不是‘玲’”）。
4. 每次修改后重新做一遍4.2第一、二步，只核修改过的区域和数字。
5. 修字最多2轮；2轮后仍有问题，交付时如实列出。

清晰度问题（第三步）也按同样办法局部重画：提示词写“同样的字，笔画更粗更清楚、与底色对比更强”，或加一层与风格一致的浅色承托（撕纸、色块、细框），不整图调色。

## 5. 先交长图，再问交付格式

审查通过后，先把成品图（原生尺寸）发给用户，附两三句说明：风格、借鉴了哪几张参考、修过哪些字（如有）、未核实的事实。

然后**一次性问**：

> 这张需要做哪些后续？（可多选）
> ① 印刷版（A3 300dpi，可加3mm出血）　② 可编辑源文件（文字可改的SVG/PDF）　③ 其他尺寸（如横版/方图/朋友圈）　④ 局部修改　⑤ 不需要，就这样

- **① 印刷版**：`python -P scripts/export_print.py <图> --size A3 --dpi 300 [--bleed 3]`。比例不同时脚本**扩边**（取边缘颜色延展）而不裁切，扩边超过5%会提示；放大倍数超过2.5倍会提示“建议用高清放大工具或以更高原生尺寸重生”。导出后实际打开检查文字边缘是否发虚。
- **② 可编辑源文件**：
  1. 用局部编辑把图上**所有文字去掉**，得到无字底图（插画、图标、装饰线保留）；
  2. 按原图位置量出每组字的位置、字号、颜色，写成 `layers.json`；
  3. `python -I scripts/build_editable_svg.py layers.json -o poster_editable.svg`，用真实字体（思源黑体/思源宋体/阿里巴巴普惠体或用户指定字体）重建文字层；
  4. 说明：艺术字主标题若保留原样就是图片层，不可改字；可改的是正文、日期、电话等文字层。
- **③ 其他尺寸**：同一提示词换画幅和分区重生，不拉伸、不硬裁原图；重生后重新做4.2审查。
- **④ 局部修改**：按[提示词模板](prompt-templates.md)第7节局部编辑，其余不变。

## 6. 一次出完：标题、插画、正文同一次生成

一键出图**只生成一次整图**，正文不再第二步补画——分开画的正文和画面常常不搭，字也容易过大压住图标。

- 文字多（101–160字）时：资料允许精简就先精简（阶段卡1第3节）；不能精简也照样一次出，提示词里写清每组字的大小档位。
- 提示词里必须写：**正文中等字号、小于小标题，不压住图标、插画主体和装饰；每组字和图标之间留出空隙**（第9节模板【排布约束】）。
- 出图后某几处字错或糊：按4.3只蒙版重画那一小块（局部修字不算“分开生成”），不重画整段正文。
- 正文大面积错乱时：精简文案、强调易错字后整张重生，不改用两步。

## 7. 记录

`state.md` 只写：模式=一键、风格（抽到的选项和选中的编号）、画布、母本、计数结果、参考编号与借鉴点、提示词、生成文件路径、选用哪张及理由、修字记录、交付格式。
