# 语言版本与实际行数

默认中文，其他语言按用户要求或明确的服务对象语言需求；A06身份不自动等于英语，其他受众也可请求双语。没有译文时由当前母本翻译并标待语言审阅，不声称存在未交付备用译文；单语任务译文检查为不适用。

各实际语言分别生成主题字与正文：主题字3横排＋2竖向组合，正文直接跟随本语言已选主题字派生，完整排版前按21模块确认各语言标题正文同图合览。中文竖排字符正向、注明列序；英文竖向用完整横向词组自上而下组成窄栏。数字、电话、邮箱、完整日期/区间/日期加时刻保持横排完整单元，优先于标题方向；日期同行按[21](21-body-type-size-and-spacing.md#语义小标题独立生成与日期同行)。竖向标题安全句读省略按[05](05-style-spec.md)，另存准确展示文案，不省略数值、范围、条件或专名功能符号。

各语言保持相同画布方向/比例、底图、主体构图和信息分区关系，只在共同分区内适配文字框、字号、断行和行距。按母本逐项配对数字、专名、时间地点、费用、否定、条件、并列项及求助语境；修订按[02](02-master-copy-rules.md)，不为齐行改已锁定译文或删事实。

行数从含空格、标点与实际字体字宽的真实排版读取；旧中文25字/行、英文49字符/行仅为估计。只有项目明确要求同字号、英文最多多1行、每项最多3行时才实测该约束，否则以可读性和语义为准。

中文核对母本文字、生成字形和最终缩放结果：错漏字、粘连、标点、断行与关键单元完整性；OCR只记录实际运行差异，副本相同不证明画面正确。报告每组语言、文字层类型、栏宽、实际行数和语义状态；真实字体记字体/字号，位图记文件、像素和放置尺寸，不冒称可编辑字体或实测pt。预测写“估计”。两次实际审查按[13](13-layout-workflow.md)，全量艺术字覆盖按[18](18-full-art-type-and-required-icons.md)。
