# 横版16:9与适老信息海报：版面速查

一键出图写【版面分区】、分步模式做空间规划时查本表。参考编号见 `assets/reference-posters/` 的 C/H/E 组（`find_reference.py --library posters --query "横版"`）。

## 1. 横版五种常用构图

| 构图 | 分区（画布百分比） | 适合 | 参考 |
|---|---|---|---|
| **左文右图** | 左40%：标题→副标题色条→编号要点；右60%：主体插画；右下角：日期/二维码/主办信息块 | 公益宣传、讲座、通知 | H01、H03（反向）、H11、C05 |
| **右文左图** | 左55%：主体；右45%：标题＋副标题条＋主办小字 | 发布会、活动主视觉 | H03、C01（反向） |
| **中轴标题＋两侧场景** | 中部40%宽：竖排或居中书法标题，红日/圆形后衬；两侧：场景框景；底部10%：信息横带 | 节日、敬老 | C03、C08、H08 |
| **动线时间线** | 标题左上；中部一条横贯的虚线/路径；3–5个定位针或圆点节点，每个节点“日期＋小标题＋一行说明” | 系列活动、日程、步骤 | H04、WP03（侧栏变体） |
| **上标题·下三栏** | 上35%：标题＋副标题；下50%：三个并列信息块（胶囊/卡片，图标在上、文字在下）；底部10%：通栏服务条（地点｜时间｜电话，用细竖线分隔） | 服务指引、多项活动 | C07、C02、E02（报刊变体） |

横版要点：
- 标题紧致外接框约占画布面积 15%–25%（比竖版小），但字高不小于画面高度的 12%。
- 横版阅读路线是“左上→右下”的Z形：标题放左上或中轴，电话/二维码放右下。
- 信息块最多 3–5 个；更多时改用“动线时间线”或分两张。
- 两侧边缘各留 5% 安全区；电子屏/公众号头图另外避开右下角缩略图裁切区。
- 横版最容易“上标题、中插画、下一行小字”平铺直叙，至少用一个[字图交互手法](linking-and-decoration.md)（第7节）打破：如时间线定位针、副标题色条、编号三步＋弯箭头（H01）。

## 2. 适老信息海报要点

| 项目 | 做法 | 参考 |
|---|---|---|
| 字号 | 关键事实（日期、地点、电话）在海报上是第二大的元素，仅次于主标题；正文不小于阶段卡4规定 | D01、E01 |
| 对比 | 正文与底色 ≥4.5:1，关键信息 ≥7:1；黄底黑字、米底深棕字、深色信息条白字都很稳 | E01（黄黑）、E02（米底蓝黑） |
| 时间放进物件里 | 把“日期＋星期＋时刻”写进门框、日历、黑板等物件里，比单独一行更醒目 | E01（门框里写“1024 本周二 21:00”） |
| 对错对比 | 须知、改造、防诈类用“✗ 错误做法 / ✓ 正确做法”成对漫画，红叉绿勾 | E02 |
| 编号竖排小标题 | 每条要点配编号和醒目色竖条小标题，一条一个画格 | E02 |
| 要点用信息条 | 底部深色通栏信息条，白字分条列出要点（每条前加圆点） | E01 |
| 真实照片 | 照片人物＋手写大字＋关键词下划线，亲切可信；照片上的字要加描边或放在暗部 | E03、E04、E06 |
| 避免 | 细体字、浅灰字、字压在复杂纹理上、只用颜色区分信息（色弱看不出）、“老”“弱”等让老人不舒服的词 | — |
