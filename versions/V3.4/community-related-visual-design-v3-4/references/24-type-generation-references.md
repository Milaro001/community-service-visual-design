# 字体参考：选具体字例，再融合生成

TG01–TG57 为 57 份优先视觉参考原图，编号不代表 57 款已识别字体。完整字例、位置、笔形、语境、配色及正文简化只维护在[索引](../assets/type-generation-references/index.json)，也可用[离线图库](../参考图库.html)浏览。执行[强制偏好](25-mandatory-design-preferences.md)。

## 全库巡览，再筛字体及字组排版

当前任务首次主题字设计时，一次取得全库目录与初筛短名单；实际查看全部缩略巡览图覆盖TG01–TG57，再结合主题含义、情绪、行动、受众、底图和组合确认入选原图/字组。相同`catalog_version`且上下文可用时复用巡览；改主题/风格只对全库重筛，不重看已巡览图。索引/源图变化或上下文丢失才补读受影响内容。正文沿用已选主题字，不重扫全库。

```sh
python3 scripts/select_type_references.py --catalog --semantics "邻里 陪伴 温暖" --limit 8
python3 scripts/select_type_references.py --semantics "成长 运动 活力" --layout staggered --limit 8
python3 scripts/find_reference.py --library type --id TG46
```

全库目录返回57条精简笔形/语境/排版记录、版本和7张缩略总览路径；同时给`--semantics`可用同一次扫描返回`shortlist`，后续仅重筛时省略`--catalog`；不能先取索引前3条当全库筛选。短名单先看语义适配，再对相近匹配按核心笔形轻度去重；摄影/横排等附加标签不算新笔形，同分不按TG编号排优先。返回匹配依据、form_families和form_family_counts；无笔形观察不当作独立方向。`--query`是必须同时命中的笔形/排版词；`--semantics`是含义适配线索，不要求原样例出现当前标题。无匹配显式调整条件，不按编号补前几张，也不为轮换而选不相关字体。若短名单明显集中，结合已巡览全库判断是否有同样适合语义/受众的不同笔形；没有就保留集中结果，不强凑配额。

字体排版参考随`type_layout`一起读取：横排、竖排、叠排、错落、侧组、穿插填隙、弧形或网格及可见语义辅助。合集先定位具体字例；同款白底/摄影是对照，不虚报两种字体。总览只用于比较，入选图的细笔画、数字和小字仍看原图。源图哈希不符则不使用旧观察，不猜字体名称或样例字符。

## 统一字形与当前主题

1. 以当前底图风格、明暗、纹理、留白，以及主题语气、关键词、受众、显示尺寸为依据；已有标题是正文的风格锚点。
2. 可从一例提基本笔形/字腔，从兼容例提端点、材质或组块关系。记录各例所取特征，统一笔画分量、高宽、端点、倾角与字距，避免逐字换样式或字腔粘连。生成完整母本文案；缺字按同系笔形生成，不能抠样字、删替字或缩句。
3. 配色呼应本次底图与主题，样例色彩不自动继承；当前字后局部对比仍须成图核查。关怀/行动/文化的风格关联只是可调起点，不能固定为圆润/斜体/衬线；当前受众、底图和实际标题语义可支持其他表达。新意来自笔形、组合节奏和语义关系，不以参考年份或叠加立体/发光效果判断是否“潮”。图形不代字，标准安全标志按适用规范保留。
4. 正文沿用本轮查库记录，按[21](21-body-type-size-and-spacing.md)继承主题字气质并简化影响阅读的效果；小标题独立生成并保持统一区别色。现有来源不适配清楚正文时仅补查具体字例，不重扫全库或另开方向选稿。
5. 按[实际生成流程](18-full-art-type-and-required-icons.md)写入准确文案、TG 编号/路径/子图、11模块具体语义辅助方案、融合与正文简化、底图/语境/配色、排除项。工具支持参考图时传入已查看原图并指定字组；否则用真实观察描述并记录方法。生成及合成后逐字、数字、透明度、裁切、缩放与局部对比检查分别留证，不能把参考匹配当作已生成或已验收。

匹配由 AI 内部完成，不增“选字体参考”关卡；主题字5款选择按11模块执行；正文直接派生，标题正文合览确认按21模块执行。

## 最小匹配记录

每种文字用途留下面字段；可共享来源，但分别说明适配。`type_library_match_and_context_fusion_current` 按[验收约定](15-layout-contract.md)由真实查图记录判断；生成与成图状态另记。

```yaml
role: 主题字 / 小标题 / 正文 / 日期号码
mother_copy: 完整准确文案
references:
  - id: TGxx
    path: 实际图路径
    sample: 可辨文字或具体子图位置
    inspected: 实际查看方式与时间
    take: 所取笔形、比例、端点、组块或配色关系
fusion: 怎样统一字形；正文怎样简化
semantic_design: 关键词含义→笔形/节奏/布局，如何在实际资产中可见
semantic_auxiliary: 主题字的符号/短线/延展形态、对应含义、相对位置、实际出图与裁切合成保留；正文不套用
type_layout_take: 参考的具体组合方式，如何按当前文字长度/语序转化
catalog_version: 本轮57图巡览版本与短名单/排除理由
context_fit: {background: 当前底图, semantics: 主题语境与受众, palette: 配色及局部对比}
exclude: 不迁移的装饰与样例事实
generation: 提示词与实际工具记录；传图或观察描述方式
render_review: 当前资产/成图版本与核查证据或未验证项
```

## 来源边界

图片仅作视觉研究，截图黑边、UI、品牌、水印、作者/版权行、样例文字与日期不进入成品。棋盘格不证明透明 alpha；“免费商用/高级黑体”标签不证明真实字体名称或许可。按当前母本保留繁简与准确事实，不照搬拼音作翻译、主标题承托框、穿字曲线或旋转散排英文。TG39/TG41 的不稳识读、TG46 中拉丁不一致及 TG49 阅读次序以原图位置定位，不能改写母本来迁就。
