# 图标和插画风格匹配

先语义/位置，再视觉。普通辅助图标以邻近已定正文的笔画分量、端点/圆角、线性/面性作搭配锚点，以已选底图确定质感、视角与光源；呼应整体主辅色，不机械复制标题的立体、描边或纹理。对照实际字形核查视觉分量和负形，优先同库同系列；近似图标仍须语义正确并有文字标签。来源/许可按[06](06-icon-sourcing.md)，强制类别与入图按[18](18-full-art-type-and-required-icons.md)。

未定稿可用单色骨架；精修普通辅助图标按语义配色，同语义同色（如饮水水滴蓝色），与主题协调，不随机换色或固定历史色值。明确单色风格/用户新要求优先。同组图标保持填充、笔形和视觉分量协调，纸艺海报也可用克制线性/面性图标，不强制全部AI立体化；许可允许时可改色/尺寸，不能改语义。

左侧正文图标的实际可见图形稍大于邻近单行字形，优先实色并留辨识负形，可从字形高度1.3–1.6倍探索，缩略检查后调整；不把透明画布当图形尺寸。图标靠近对应文字、基线协调、间距和局部对比清楚，容量预检计入放大尺寸，不挤小正文。规范符号保留标准形状/颜色，不因实色偏好改造。

急救120、报警110各保留准确用途/号码；无合适医疗/报警图标可共用普通电话图标，用文字区分，不能错配医疗符号或冒官方徽标。强调色可呼应语义，不能代替标签。

普通插画可用实际生图工具改变质感，先看参考后生成/编辑，核对新增文字、品牌或误导服务细节；规范标志、警示色、禁止符号、真实Logo和地图/路线按已确认源图保真。保存源头和修改过程，AI改绘不消除许可义务。每语言合成后查看语义、完整文字/号码、清晰度、裁切遮挡及位置；能力不足提供明确未完成的构图/提示交接。
