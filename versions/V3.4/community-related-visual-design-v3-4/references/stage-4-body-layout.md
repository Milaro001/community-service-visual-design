# 阶段卡4：正文与排版

本阶段在已选的“底图＋标题”整图上直接排入正文、图标和装饰，最后让用户选排版。正文上图后**不单独询问**。

## 1. 正文怎么上图：按字数二选一（不再“素材页→逐组裁切→贴图”）

先用 `python -I scripts/count_copy.py state.md --body-only` 数正文（主标题以外的上图文案）。

| 正文字数 | 做法 |
|---|---|
| ≤80 | **整图编辑一次**：以阶段3选定的“底图＋标题”整图为输入，用图像编辑一次把全部正文、图标、大数字、装饰线画进去（提示词用[提示词模板](prompt-templates.md)第9节的【字图关系】【版面分区】【必须准确显示的文字】三块，开头写“在这张图上继续排入以下信息，标题和主体保持不变”）。字、图标、插画同一笔触，天然有交互 |
| >80 | **分区编辑（默认）**：按画面区域把正文拆成2–3批（每批≤60字），每批用蒙版只编辑对应区域，用[提示词模板](prompt-templates.md)第10节，正文与标题同一支笔的艺术字 |
| 用户明确要求“正文用标准字体、方便改字”时 | **真实字体排版**：正文用有性格的真实字体直接排（见下表，`scripts/patch_text.py --spec`） |

整图编辑时同一区域重画2次仍有错字：先按一键出图卡4.3第2条拆字重画；仍错才用真实字体贴补这一处，并在交付说明里写明。普通电脑字体和手绘/水彩画面放在一起会割裂，不作默认。

真实字体选择（只在上述情况使用；本机没有时用思源黑体/思源宋体替代，并在 `state.md` 记下）：

| 风格 | 小标题 | 正文 | 数字 |
|---|---|---|---|
| 手绘暖调 | 站酷快乐体 / 阿里巴巴普惠体 Heavy | 阿里巴巴普惠体 Medium | 阿里巴巴普惠体 Black |
| 国潮水彩/水墨 | 思源宋体 Heavy | 思源宋体 SemiBold | 思源宋体 Heavy |
| 简约扁平/三维 | 阿里巴巴普惠体 Heavy / 思源黑体 Heavy | 思源黑体 Medium | 阿里巴巴普惠体 Black |
| 复古版画 | 思源宋体 Heavy | 思源宋体 Medium | 等宽或粗宋 |

无论哪种做法：
- **小标题**单独成组，用统一的醒目色（辅色或强调色），配母题小色块或胶囊底。
- **日期、时段、电话、普通数字**统一用强调色，冒号、连字符、区间线同色；用途标签用正文色。按第7节“大数字图形化”挑2–3个放大。
- 每条完整日期、日期范围、日期加时刻、电话、邮箱各占同一行。
- 重点提醒、禁止事项完整保留否定词和条件，关键词用下划线/荧光笔底色标注。
- 上图后对照母本逐组核对（先盲读再对照，方法见[一键出图卡](oneshot-mode.md)4.2）；错的组只局部重画这一组。

旧做法（正文素材页一次生成→逐组裁切→合成）只在工具不支持图像编辑、且必须用艺术字正文时使用。

## 2. 图标

字少（约60字以内）时，先按[串联与装饰系统](linking-and-decoration.md)第11节做语义图形化：标签词换图标、承托形状跟词义走。

每个适用类别至少放一个图标，同类相邻信息可共用：

| 信息 | 图标 |
|---|---|
| 地址/场所 | 定位、场所 |
| 日期/时段 | 时钟、日历 |
| 联系/预约电话 | 电话 |
| 邮箱 | 信封 |
| 风险/警示 | 警示 |
| 行动/主题 | 对应动作或主题图形 |

- **整图编辑路线**：图标在编辑时与正文一起画出，提示词写明“icons drawn with the same brush/line quality as the illustration”，并按[串联与装饰系统](linking-and-decoration.md)第7节做“图标当容器”。
- **真实字体路线**：来源顺序 iconfont.cn → 用户提供/本地 `assets/icons/` → Tabler Icons（MIT）或 Pictogrammers MDI（Apache-2.0）→ 自行绘制；底图是水彩/手绘/版画等非扁平风格时，矢量图标要按底图笔触重绘或用图像编辑统一质感，不直接贴规整矢量图标。在 `state.md` 记一行来源和许可。
- 风格：同一套系列，笔画分量对齐邻近正文，实色面性优先并保留清楚负形；可见图形约为邻近单行字高的 1.3–1.6 倍。
- 按[串联与装饰系统](linking-and-decoration.md)给图标加统一底座或母题处理。
- 规范安全标志保持标准形状和颜色；急救 120、报警 110 共用电话图标时用文字写明用途。

## 3. 排版尺寸与规则

| 项目 | 规则 |
|---|---|
| 主标题 | 紧致外接框占画布 25%–35%；**主标题背后不加整块矩形底框**；允许与主体局部穿插（见串联与装饰系统第7节） |
| 正文字号 | 3200×4000 画布上，正文主要字形可见高度 95–110px（默认约100px）；其他画布按宽度相对3200px换算 |
| 行距与组距 | 组距明显大于行距；笔画、升降部不相碰 |
| 换行 | 按语义断行；完整保留否定和条件；避免孤字、行首闭合标点 |
| 横线 | 主标题与其后的提示/行动正文之间一条清楚横线；独立警示组与行动区之间一条短横线；服务区上方一条横线。横线长度随字组宽度和轴线，不穿过文字、图标或人物 |
| 服务区 | 标题在上方时：地点/时间左下左齐，咨询电话右下右齐；标题在下方或侧边时按真实留白调整 |
| 主体 | 已选底图的主体尺寸、比例、完整轮廓保持不变，也不缩主体给文字腾地方 |

**图文冲突时按这个顺序处理**：
1. 先调整完整文字组的位置、轴线、栏宽、断行和组距，利用连续留白；
2. 仍不够时，淡化周边的树、草、云等非关键环境（降低透明度/细节/反差或轻微虚化，用渐变过渡），主要人物、关键物件和视觉中心保持清楚；
3. 仍不够时，加与主题协调的承托形状：开放细线框、弧形色域、不规则纸片、低对比纹理场；整段矩形底板放在最后考虑。

## 4. 排版流程

1. **结构匹配**：沿用阶段2看过的参考，挑适合当前文字量的结构，把标题、主体、正文、服务区、阅读路线一一对应到本次内容，写成第9节模板里的【版面分区】。
2. **出候选**（常规3款、快速1款）：
   - 整图编辑路线：每款以“底图＋标题”整图为输入编辑一次，3款在正文栏数/分组、信息组位置或动线上有可见差异；
   - 真实字体路线（仅用户要求时）：先整图编辑画出小标题、大数字、图标和装饰，再按分区排入正文。
   不再先用普通字体初排、再换艺术字合成——上图的就是最终字。（分区编辑前可以用普通字体在草图里快速试排位置，只用于内部定位，不展示、不交付。）
3. **唯一一次审查**（看整图、缩略图和底部局部）：
   - 文字与母本一致（先盲读再对照），断行合理；
   - 正文字号达标，层级清楚，阅读路线顺；
   - 文字没有压到主体、关键动作和视觉中心（第7节允许的“标题与主体局部穿插”除外）；
   - 局部对比够，边距足；
   - 横线、服务区、图标位置正确；
   - 串联装饰系统和字图交互手法落实到位（见对应文件末尾的检查清单）。
   有问题就局部改，改完再看一眼确认。
4. **展示**：各候选等比排成总览，左侧标 L1/L2/L3，图外简注结构特点，问用户选哪款（可组合、可修改）。快速模式只有1款时直接展示并问“是否需要调整”。用户明确回答后写进 `state.md`，进入[阶段卡5](stage-5-finish-export.md)。
