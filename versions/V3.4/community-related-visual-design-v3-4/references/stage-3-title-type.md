# 阶段卡3：主题字

主题字 = 主标题的艺术字，每种语言单独设计、单独选择。

## 1. 查字体参考

- **常规模式**：运行 `python -I scripts/select_type_references.py --catalog --semantics "<主题关键词>" --limit 8`，看完全部8张字体巡览页（TG01–TG65），再结合短名单打开入选原图看具体字例。
- **快速模式**：省略 `--catalog`，只取语义短名单，打开1–2张原图。
- 横版、老年、节日、传统题材优先参考 **TG58–TG65**：
  - 行书/行草、飞白、长拖尾：TG58 TG60 TG62 TG63 TG65
  - 粗笔干墨、两行错位：TG61 TG64
  - 厚重粗宋/方黑（清楚郑重）：TG59
- 从参考里借：笔形、端点、粗细、字距、组合方式（横/竖/错落/大小字）。样例文字、印章内容、品牌照搬不用。

## 2. 每款先写语义设计（一句话）

`关键词含义 → 笔形/笔势 → 组合节奏 → 语义辅助元素 → 与已选底图的配合`

例：“登高望远 → 首字长横外挑、末笔上扬 → 两行错位 → 右上一组飞鹤短线 → 压在底图左上的雾气留白上”。

**语义辅助元素必须有**：与文字同次生成的少量符号、短线、弧线、印章或延展笔画，位置贴近字组，并且和关键词有说得出的关联（风线表示“风”、相携的两条弧表示“同行”、印章表示传统节日）。数量克制，不遮字、不替字。

## 3. 数量与差异

| 模式 | 每种语言 | 要求 |
|---|---|---|
| 常规 | 3款：H1、H2 横排 + V1 竖排 | H1 整组左齐、右侧自然参差；H2 明显错落或大小字对比；V1 竖排 |
| 快速 | 2款：H1 横排 + V1 竖排 | H1 任选左齐或错落 |

- 各款在笔形、组合和语义辅助上有明显区别，不只换颜色。
- 竖排：中文每列从上到下、各列从左到右，字符正向；英文用完整词组排成窄栏。竖排标题可省略纯装饰标点，“3–6岁”“0.5”这类功能符号保留。
- 颜色取自阶段2的色板。
- 主标题紧致外接框面积约占画布 25%–35%（排版时实测）。

## 4. 生成：直接写在已选底图上（不再白底生成再抠图）

默认用**图像编辑**把主题字直接画进已选底图的标题区：

1. 把已选底图作为输入图；工具支持蒙版时，蒙版只涂标题区（阶段2空间规划里写好的区域）。
2. 按[提示词模板](prompt-templates.md)第4节写提示词，但把【用途】改为：“在这张底图的{标题区位置}写上主标题艺术字，与底图同一种笔触、纸纹和光线；标题与底图中的{某物件}局部穿插；底图其他部分保持不变”，并删去“纯白背景/便于抠图”。
3. 每款各编辑一次（快速2款、常规3款，可并行），得到的就是“底图＋标题”的整图，后面排版直接在它上面继续，不再缩放合成。
4. 生成后逐字核对：错字、漏字、多字、粘连、相近字混淆；错的那款只对标题区局部重画。

**只在这些情况下退回白底生成再抠图**：工具不支持以图生图/图像编辑；或同一款在底图上编辑2次仍改坏了底图主体。

## 5. 展示

三款（或两款）“底图＋标题”整图并排成总览，左侧标 H1/H2/V1（多语言加 ZH/EN），图外简注笔形和语义设计，问用户每种语言选哪款（可组合、可修改）。用户明确回答后写进 `state.md`，进入[阶段卡4](stage-4-body-layout.md)。
