# 排版阶段：结构、容量与两次渲染

按[21模块](21-body-type-size-and-spacing.md)取得当前标题正文合览批准后进入完整排版；已有选择沿用，两次渲染审查由AI内部执行。

设计规则引用各自唯一来源：[25当前偏好](25-mandatory-design-preferences.md)、[10位置/图底](10-position-and-whitespace.md)、[21正文字号/分组](21-body-type-size-and-spacing.md)、[26换行/净空](26-linebreak-and-whitespace.md)、[18艺术字/图标](18-full-art-type-and-required-icons.md)、[15验收/状态](15-layout-contract.md)，不在此重列阈值。


## 1. 分组、图标与结构

读取当前母本、受众、画布、已选资产及N4前的[28构图计划](28-background-composition-planning.md)。每组记录`母本ID / 完整文本 / 语言 / 阅读顺序 / 用途 / 强调等级 / 是否必须展示`；真实层级优先，不为凑四层删内容或另写CTA。

已有底图/直接排版若缺当前全库巡览，先按[09](09-reference-library.md)补齐；已有N4巡览及参考映射则复用。按[23](23-priority-layout-references.md)从全库筛2–3个适配当前字组/容量的具体原图或子图，已查看且适用的记录复用，缺失才打开/补查。提取方法不清或适配冲突才补读[14](14-reference-structure.md)；稀疏口号图不能证明长文容量。

核对N6图标库存及来源/许可，只补缺失或失效项；按18实际合入初排，尺寸和间距计入容量。已有图标不重新检索/生成，检索记录不代替入图。

## 2. 容量与清楚字体初排

先由受众/媒介确定最低可读尺寸，再以实际字体、完整文本和断行计算各组宽高；估计只记估计/未验证。盘点连续留白、安全区、主体保护和必要间距，按真实可见字形含装饰边缘检查，矩形面积足够不等于能容纳。密度作为结构筛选信号而非删减上限：≤2短组通常低密度，3–5组中密度，多组/长段/双语高密度。

筛选同底图适配的3种组织系统，制作默认3款、适用时3–5款完整候选；差异来自阅读路线、分栏、标题锚点或主体／信息组关系；依25先通过文字分布/连续留白形成结构，周边环境按需减弱，必要承托才按10选择；保留主图尺度和中心清晰度，不能只换色或换框凑数。用许可适用的清楚字体初排，记录位置、实际换行、字形尺寸、行距、对齐、颜色、背景处理和版本。初排字体只用于结构验证，不另选稿或代替最终艺术字。

容量不足按10/21/26优化分组、栏宽、断行、位置和间距；不删锁定文案、压扁文字、偷偷降用户尺寸/主体比例或增加页数。仍无可读解时给具体受限区域，仅问需要变更的实际约束。图底冲突、正文承托与主体保护按10/25执行，字后柔化不是必做步骤。

## 3. 第一次实际渲染审查

打开清楚字体初稿整图、缩略图、目标显示尺寸与关键局部，检查本阶段母本、断行、容量、最低阅读尺寸、层级、阅读路线、主体保护、边距和背景对比；证据绑定初稿文件/版本。未完成的艺术字覆盖、候选选择或最终配色是后续义务，不阻断初排，也不提前记通过。

结构失败先修复。通过的布局、断行、文本和保护区域作为艺术化参考，不以“艺术化会更好”跳过实际初审。

## 4. 艺术化与第二次实际渲染审查

引用已选主题字、合览获准的正文字组及通过初稿，先盘点库存，仅按18生成确实缺失或失效组；提示带准确文本、逐行断行/列序、分组、色彩/笔形关系和最大区域。先校对资产，再逐组等比缩放并合入已选底图/图标；跨候选字组库存复用按18，不整图重生成替换已选资产。

第二次打开艺术化合成图并重新测可见边界，艺术化改变字宽/高、描边、投影、透明裁切，不能沿用初稿坐标/状态推定通过。核对全量生成覆盖、图标实际入图/许可，以及文字、字腔、尺寸、容量、对比、层级、遮挡、旧位置残留；按15/18修失败组并回查受影响项。每语言每完整候选分别留证据，分数不替代用户审美选择。

## 5. 选择、精修与记录

按[22](22-selection-overview.md)展示当前完整候选编号总览，再单独选择整体版式；内部两次审查不替代该选择。选定后按[19](19-final-color-and-readability.md)精修/配色比较，已有选择和授权修改沿用。

最小记录：母本版本、参考/映射及理由、真实容量、各候选结构、初审文件/结果、艺术字和图标资产证据、终审文件/结果、未验证项；状态和后续受影响回归见15/20。
