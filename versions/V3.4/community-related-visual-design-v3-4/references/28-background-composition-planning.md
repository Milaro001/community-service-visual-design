# N4底图生成前的构图预规划

资料／母本整理后、首次底图生成前执行下列内部规划，不新增确认。已有底图沿用，只回查受影响区域容量；数量／风格／位置覆盖依[29模块](29-background-style-and-position-coverage.md)，分量与文字约束依[25模块](25-mandatory-design-preferences.md)。

## 1. 文案匹配参考结构

锁定画布、方向、语言、媒介、信息组及不可拆单元，用最长语言正文预检。先按[09](09-reference-library.md)完成全库布局巡览，再依[23](23-priority-layout-references.md)从完整库匹配骨架和具体原图/子图，通常取2–3个精读；P15–P17可看主体／图片区，P05–P14及P18–P23可看文字／网格，按内容选择。

## 2. 三张空间规划

为A–C各记录：具体风格／手法、方向归属、参考编号／子图、主体横向主位置与纵向锚点、标题／正文／服务区域、阅读路径、环境延展、主体与实际视觉中心保护区、可按需淡化的周边环境、连续正文区及拟用图文关系。区域可用0–1范围并标estimate，不作实测容量或像素比例pass。

依29模块先核数量、必含方向和横纵覆盖；同时规划完整字形、图标、横线、行距／组距。长文用宽而连续区域，服务区预留完整横行，不等生成后再缩主体／文字。纯文字参考也须转换为含真实主题物及环境的构图。

## 3. 写入实际生成提示

写明当前主题、参考结构、明确造型手法、主体位置／尺度、环境、连续文字空间、服务区和保护对象；能传图时引用所选原图／区域，否则如实描述观察。N4不生成正式标题、正文、日期、地点、电话、二维码；参考灰形、叉线、教学网格不进入底图。

底图须是完整主题画面。摄影／立体可用自然空间；简笔／几何用形状、叠放、尺度、色块、负空间建立层次，不强制真实透视或立体材质。优先预留连续无框正文区与主体呼应关系，保护中心细节，周边环境可疏朗/渐淡；正式文字后续合成，已有主图排版时锁定尺度。图文处理优先级依25、必要承托依10，不预设矩形底板或中心字后虚化。

## 4. 成图复查与后续沿用

逐张实际打开，检查位置、分量／辨识、空间形状、环境、保护对象、多语言共用构图及完整信息能否容纳。未实现则定向修复／换结构；提示不是证据，同策略连续无效须调整。

N4仅做容量估计，主题字／正文及两次排版审查依后续流程。选定后沿用参考→区域映射，再按真实字形测量；不能因参考的框、实验路线或小字改变当前用户规则。
