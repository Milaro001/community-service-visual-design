## 全库阅读，再匹配结构

当前任务首次构图或排版前运行完整目录，不受检索默认3条限制：

```sh
python3 scripts/find_reference.py --catalog-layout
```

完整覆盖147份源图：P23＋A/B75＋T4＋骨架45；3份既有总览只作导航，TG57字体另按24阅读。返回全部源图/编号、`catalog_version`、17张巡览图和`catalog_current`。先实际查看全部巡览页，逐份理解主体/文字分区、层级和阅读路线；合集或长图的结构看不清时放大原图/分区补看，不能把缩略可见当细部已读。然后按当前文案量、语言、受众和底图筛匹配原图/子图，通常2–3个结构足够；不按编号先取前三张。

记录库版本、实际查看的页/源图、看不清或未读项、入选结构及理由。相同库版本且上下文可用时，N4→正文→完整排版沿用该巡览；改主题只对完整库重筛。新增/替换源图或总览校验失效时先补读并更新总览，不复用旧观察；上下文缺失据状态补看。已有底图或只做排版仍须补齐缺失巡览，不重生成底图，也不增加用户选择。

目录/哈希仅证明来源与覆盖，不能证明AI已看图或当前文案容量。`catalog_current:false`时不使用返回为空的旧巡览图；维护时更新`assets/layout-atlas/index.json`及相关总览。骨架不代替实例视觉阅读。

`assets/wireframes/D##_S#_01.png`的D/S对应[01分类](01-classic-input-taxonomy.md)；45张由原交付说明标注项目自制，并非独立版权鉴定。只取信息顺序、区块、阅读路径和入口，不把占位矩形/连线当成品元素。B组按领域名称映射：D03养老→B04，D06就业→B03。

## 直接匹配实例结构

A/B的75张不同源图已实际看图标注密度、主要信息区列数（含图标条目）、标题锚点、主体位置、文字区和阅读路线；同图别名共用观察记录。长图、折页、展示页、混合布局及模糊区域的局限随结果返回，列数不确定用null；局部功能栏不等于多栏长正文。密度描述源图的信息量，不证明本次长文容量、字形可读性或许可。

领域是社区服务适配标签，尤其同图跨领域别名，不等于原图真实主题；实际可见结构以观察记录为依据。

```sh
python3 scripts/find_reference.py --library posters --query "分栏 日期"
python3 scripts/find_reference.py --library posters --density medium --columns 2
python3 scripts/find_reference.py --library posters --subject-position left --text-zone right
```

`--density low/medium/high`、`--columns 非负整数`、`--subject-position`、`--text-zone`、`--title-anchor`、`--reading-route`按可见结构筛选；具体枚举首次用`--help`查询。字段条件与关键词均为AND，不足时显式减少条件，不代选。0列指没有成组正文/条目；null/未观察不能满足指定列数。中文关键词也可查“长文案”“双栏”“主体偏左”等。

排序优先已看图结构，再看领域和已整理的适配信息，不按路径中重复词的次数排序；`--skeleton`仍只是关键词提示。结构记录须与索引及实际源图SHA一致；只哈希粗筛后可能命中的路径，同图别名每次调用只验一次，无持久缓存。源图已变则撤去旧结构、重按原条件判断，改源图须重看并更新索引。继续实际打开命中图核对本次适配，不把记录当成当前成图验收。

主题字、正文、小标题和日期号码的具体字例匹配按[24](24-type-generation-references.md)；实例结构/信息组映射按[14](14-reference-structure.md)，两次排版审查按[13](13-layout-workflow.md)。选稿顺序仅由主流程定义，展示按[22](22-selection-overview.md)，已有选稿沿用。

第三方实例供用户私人研究，不能抠图、去水印、复制品牌/文案/号码或作为成品背景；新图须自行制作/取得适用权限。全量艺术字证据见[18](18-full-art-type-and-required-icons.md)，普通字体加粗不等于生成艺术字；不要把生成位图称为可编辑字形。
