# 阶段卡1：开工、资料与母本

## 1. 先读资料，不先问模式

1. 先读完用户给的PDF/文字/图片，按第2节拆分、按第3节写母本。**开工时不问“常规还是快速”。**
2. 母本写好后数上图文案：`python -I scripts/count_copy.py state.md`，按下表决定模式：

| 情况 | 模式 |
|---|---|
| 用户明确说要常规/快速，或想“一步一步看”“每步自己选” | 用户说的模式（阶段卡2–5） |
| 用户没说，上图文案 ≤160字 | **一键出图**（[一键出图卡](oneshot-mode.md)），直接问风格；101–160字按卡内第6节分两步画字 |
| 用户没说，上图文案 >160字 | 问一次：一键出图 / 快速 / 常规，推荐快速，并说明“文字较多，一次整图出字容易错” |

3. **唯一的开头提问**（合并成一条消息）：一键出图时用选择题工具让用户点选风格（pick_styles.py 从12种里抽）＋缺失的必要事实；分步模式时只问缺失的必要事实。只有当本次海报必需的事实缺失或互相冲突时才问事实，例如活动日期、地点、报名电话。
4. 机构名、Logo、邮箱等可选字段：用户没给就不放，也不留占位。
5. 印刷、源文件、其他尺寸：**开头不问**，出图后再问（一键出图卡第5节；分步模式在阶段卡5）。

分步模式：资料齐全时可以跳过提问直接开工。**一键出图例外：风格问题必须问并等回答**（问法原文见 SKILL.md“必经一步”），除非用户已明确选了风格。

## 2. 拆分资料

把原文拆成信息组，只拆分、不改写：

| 类别 | 例子 |
|---|---|
| 主题/标题 | 活动名、口号 |
| 服务对象 | 适用人群、资格 |
| 时间地点 | 日期、时段、地址 |
| 行动步骤 | 报名、参加、求助方式 |
| 注意事项 | 条件、费用、禁止事项 |
| 联络 | 电话及其用途、邮箱 |

判断主骨架（选一个）：S1时间地点公告 / S2步骤流程 / S3清单条目 / S4分类对比 / S5警示禁止 / S6招募邀约 / S7数据公示（需真实数据）/ S8空间导视（需已确认地图）/ S9求助联络。

判断受众：未说明时按全体居民；老年人受众用大字、清楚分组、醒目的地点和电话。

## 3. 母本

母本 = 最终上图的准确文案，每条写成 `ID｜语言｜采用文案｜来源`，写进 `state.md`。主标题的ID用T开头（T1、T2），其他用B开头（B1、B2……），`count_copy.py` 据此区分标题和正文。

- 号码、日期、时段、地址、机构名、否定词、条件、范围、行动顺序原样保留。
- 可以直接改：意义明确的错别字、非关键标点、断行位置。
- **允许精简时可以改写长句**：资料里写了“可自行删改/可精简/仅供参考”，或用户说过可以改，就可以为版面和美观缩短、换词、合并句子（例如“本次课程全程免费，不会向您推销任何手机或套餐”→“全程免费 · 不推销”）。号码、日期、时段、地址、机构名、否定词、条件、范围**一律不改**。母本里写 `原文→采用文案`，交付时用一两句话列出改了哪几处。资料没这样说时，只在文字明显放不下时问用户一次“这几句可以缩短吗”。
- 需要先问用户：新增事实或行动、扩大承诺、改变条件。
- 通用应急号码（110/120/119）只在文案明确指向紧急行动时展示，并写清用途。
- 双语：各语言分别成母本，数字、专名、条件一一对应；没有现成译文时由母本翻译，并标注“待语言审阅”。

## 4. 画布

| 用途 | 默认画布 |
|---|---|
| 竖版印刷 | A3 297×420mm，设计稿3200×4000px，导出3508×4961px（300dpi） |
| 横版屏幕/展板 | 16:9，3840×2160px；用户给尺寸时按用户尺寸 |

写入 `state.md`：模式、计数结果、画布、语言、受众、骨架、母本。一键出图进入[一键出图卡](oneshot-mode.md)第1节；分步模式进入[阶段卡2](stage-2-background.md)。
