# 串联与装饰系统

目的：让标题、主体、正文、图标在视觉上连成一个整体，正文不再“素”。底图、主题字、排版三个阶段都执行本文件。

## 1. 统一视觉系统（阶段2定下，全程照用）

| 项目 | 规则 |
|---|---|
| 色板 | 4色：背景约60%／主色约25%／辅色约10%／强调色约5%。文字、图标、线条、承托全部从中取色。**强调色优先取主色的对比色/互补色**（橙配绿、朱红配青、蓝配橙），集中用在数字、关键词、贴纸上，让画面“跳”起来，避免全图同一色相发闷 |
| 线宽 | 全图只用2种：粗线（服务区上方横线、主分隔）＋细线（短线、框线、图标线） |
| 圆角 | 全图只用1种圆角半径（或统一直角），胶囊标签、图标底座、承托形状一致 |
| 网格 | **只有简约扁平风格**严格对齐12栏（竖）/16栏（横）；手绘、国潮、三维、版画风格只需主标题和底部服务条大致对齐，其余字组可以自由错落 |
| 母题 | 1个，来自底图主题（见第2节） |

## 2. 母题复用：必做

从底图里选1个母题，**至少在下面4处中的3处出现**：

1. **标题装饰**：主题字的语义辅助元素就是母题（如菊花瓣点在字侧、风线顺着收笔延伸）；
2. **分隔线**：横线两端或中点带母题小形（云纹端头、叶片端点、回纹）；
3. **项目符号/编号**：用母题形状做小圆点、编号底形；
4. **图标底座**：所有图标放进同一个母题形或统一圆形/胶囊底座里，颜色统一。

常用母题参考：

| 题材 | 母题 | 用法示例 |
|---|---|---|
| 敬老/重阳 | 菊花瓣、云纹、回纹、印章、红日圆、鹤 | 印章做编号底；云纹做横线端头；红日圆做标题后衬；菊瓣做项目符号 |
| 安全/应急 | 盾形、圆角三角、条纹 | 三角做警示组标记；条纹做分隔 |
| 环保/自然 | 叶片、水滴、波浪线 | 叶片做编号底；波浪线做分隔 |
| 文体活动 | 星形、速度线、圆点 | 速度线串联各活动项 |
| 邻里/服务 | 屋檐、门窗、连线 | 屋檐形做小标题底 |

## 3. 动线：必做至少1条

用一条看得见的线索把主体、标题和正文串起来，引导阅读顺序：

- **笔势延伸**：主题字的长拖尾或长横继续延伸，指向正文起点（参考 TG62、TG65）；
- **路径串联**：底图里的小路、河流、飘带、云带延伸成虚线或细线，依次经过各信息组；
- **视线引导**：主体人物的视线、手势或行进方向朝向标题或正文；
- **编号序列**：01 / 02 / 03 大号编号沿一条轴线排列，由细线连接；
- **斜线分隔栏**：顶部或底部信息用“2026 / 敬老月 / 重阳节”式斜线串成一行（参考 C07）。

## 4. 正文装饰额度：每个信息组至少1个视觉锚点

| 元素 | 装饰方式（任选） |
|---|---|
| 小标题 | 母题小色块底；半透明荧光笔式底色；左侧短竖条；胶囊标签（参考 C07） |
| 编号 | 大号描边或空心数字，颜色浅于正文；印章形底 |
| 关键词 | 强调色；手绘下划线；引号强调（参考 C07 “忆”“需”“乐”） |
| 时间/地点 | 胶囊标签或细线框；图标＋强调色数字 |
| 服务区 | 横线上方，图标之间用细竖线分隔（参考 C02 底部服务条） |
| 副标题 | 宽字距＋两侧细横线（参考 C01）；括号包裹（参考 C04） |
| 落款/日期 | 衬线大号数字＋细线（参考 C03） |

层级至少分4级：大编号/小标题 → 正文 → 标签 → 注释，用字号、字重、颜色区分。

## 5. 写进提示词的关键词

底图、主题字、素材页的提示词里直接加入对应词：

- 中文：母题复用、视觉引导线、动线串联、虚线路径连接各信息节点、统一图标底座、编号序列、胶囊标签、两侧短横线副标题、印章点缀、云纹端头分隔线、红日作标题后衬、笔势延伸指向正文、斜线分隔信息栏、色彩编码。
- English：recurring motif, leading lines, dotted path connecting information nodes, consistent icon badges, numbered sequence, pill-shaped tags, divider with ornamental ends, visual flow, cohesive design system, limited color palette。

## 6. 适用边界

- 主标题背后不加整块矩形底框；印章、短线、符号放在标题侧边或空隙。标题可以和主体**局部穿插**（主体的边缘物件从标题后方穿出或压住一个字的一角），但不能遮住笔画导致认不出字。
- 装饰全部来自色板和母题，一张图里不混入第二套装饰风格。
- 严肃警示类海报装饰克制：母题复用降到2处，动线用编号序列或分隔线即可。
- 印章内文字只用母本已有的词（如“重阳”）或做纹样，不编造机构名、人名。

## 7. 字图交互手法（从“银龄手机课堂”等参考归纳）

正文“太正太素”、图标和字“各自为政”，本质是字、图标、插画没有发生关系。下面6种手法每张海报**至少用3种**（一键出图写进提示词；分步模式在排版时落实）：

| 手法 | 做法 | 例子 |
|---|---|---|
| **大数字图形化** | 挑2–3个关键信息（日期、人数、节数、价格“免费”）做成画面第二大的元素，用强调色，可配小图标或圆形底 | “10.20”特大号；“50+”旁配人群图标；“共6节课”做成小圆章 |
| **图标当容器** | 字写在图标里面或紧贴图标轮廓，而不是“图标＋空格＋文字” | 房子线框里写“二楼活动室”；日历页里写日期；对话气泡里写电话 |
| **标题与主体穿插** | 插画里的一个物件从标题后方穿出，或主体边缘压住标题一角，形成前后层次 | 手机线框从“手机课堂”后面穿出 |
| **贴纸/徽章标注** | 1个略倾斜（5°–12°）的贴纸、对话框或圆章，放一句短呼语 | “开课啦！”“免费参加”“名额有限” |
| **虚线动线** | 一条虚线或手绘箭头从插画出发，依次连到日期→地点→电话 | 弯曲虚线串起日历、房子、电话图标 |
| **关键词标注** | 正文中2–3个关键词加荧光笔底色、手绘下划线、圈注或换强调色 | “免费”“不推销”“一对一”加下划线 |

**同笔触原则**：标题、图标、数字、线条和插画必须是同一种笔触与质感（手绘就全手绘，扁平就全扁平）。分步模式里不再直接把 iconfont 规整矢量图标放到水彩/手绘底图上——要么让图标与底图同次生成，要么按底图笔触重绘图标（提示词：`icons drawn with the same brush/line quality as the illustration`）。

**层级更丰富**：除“主标题→小标题→正文→注释”外，加入“特大数字”和“贴纸短语”两档，正文本身也允许2种字号。

## 9. 文字放开：别把字框死

规则是为了清楚，不是为了整齐。除简约扁平外，其他风格默认：

| 可以 | 例子 |
|---|---|
| 正文也用手写/艺术字，和标题同一支笔 | 马克笔小字、毛笔小楷、圆润手绘字 |
| 字组倾斜 ±8° 以内、沿弧线或物件边缘排 | 写在飘带上、沿小路弯曲 |
| 字写在物件上 | 黑板、门框、日历、手机屏、横幅、便签、对话气泡 |
| 大小跳跃，同组里关键词放大一倍 | “每周三 **上午**”“**免费**参加” |
| 信息组散落在画面里，不等宽、不对齐 | 三个便签高低错开 |
| 标题、大数字压到插画上，或被插画局部挡住一角 | 手机线框穿过标题 |

仍然要守住的：每个字都认得清；电话、日期、地址各自完整在一行；字不压在复杂纹理上（压的话加撕纸/色块承托）；老年受众时关键事实够大。

## 10. 主体要扣题，构图要多样

**先扣题：主题里的人和事必须在画面里。** 主题是“为老年人做的事”（老年手机课堂、敬老、适老化），画面里就要有**老年人**，并且看得出他们在做这件事（学手机、包饺子、散步）；不能只剩一部手机、一个物件，让人看不出是给谁的、在干什么。主体＝**受众人物＋核心事物＋动作**，三者缺一不可（纯通知类无人物主题除外）。

**再求变化**：变的是镜头和构图，不是把人删掉。每次先列3种构图，挑一种和最近几张不同的，写进 `state.md`：

| 构图 | 例子（长者手机课堂） |
|---|---|
| 近景单人 | 一位奶奶举着手机自拍开怀大笑，手机屏幕里映出社区 |
| 双人互动 | 年轻志愿者俯身指着屏幕，爷爷戴老花镜认真看 |
| 手部＋人物 | 前景是苍老的手点屏幕，背景虚化里是几位老人围坐 |
| 比喻 | 手机屏幕像一扇窗，老人从窗里探出头，窗外是热闹的生活 |
| 场景俯视 | 活动室俯视，几位老人各拿手机，桌上有老花镜、笔记本 |
| 群像 | 几位老人并排坐着学手机——可以用，但不要每次都用 |

参考图只借风格，不照搬参考图里的人物和动作。

## 11. 字少时：让字和图互相说话

上图文案较少（约60字以内）时，每张至少做3处“语义图形化”：

| 做法 | 例子 |
|---|---|
| 标签词换成图标 | “电话：”换成电话图标，“地点：”换成定位针，“时间：”换成时钟；号码、地址本身照写 |
| 承托形状跟词义走 | “免费”写在礼物吊牌上；“温馨提示”写在便签/小喇叭旁；“二楼活动室”写在房子线框里；“报名”写在门票形状里 |
| 关键词配一个小图形 | “健康”旁一颗小爱心；“安全”旁一面小盾牌；“学会”旁一个对勾 |
| 笔画局部替换 | 标题里一笔换成相关小图形（“学”字一点换成手机、“春”字一撇换成柳枝），整字仍要一眼认得出 |
| 周边小插画呼应 | 日期旁画一页撕下的日历；“共6节课”画6个小圆点进度条 |

内容词（活动名、地址、号码、否定词、条件）**不能用图形替代**，只能配图形；只有“电话、地址、时间、日期”这类标签词可以整词换成图标。

## 8. 排版审查时检查

- [ ] 母题在标题装饰／分隔线／项目符号／图标底座中至少出现3处
- [ ] 至少1条动线把主体、标题、正文串起来
- [ ] 每个信息组都有至少1个视觉锚点
- [ ] 线宽只有2种，圆角只有1种，颜色都来自色板
- [ ] 主体包含主题里的人物和动作（第10节），构图和最近几张不同
- [ ] 字少时第11节语义图形化至少3处
- [ ] 简约扁平风格：文字组与图标对齐到网格栏线；其他风格：文字没有被排成僵硬的表格
- [ ] 第7节字图交互手法至少用了3种
- [ ] 图标与插画是同一种笔触
- [ ] 强调色是主色的对比色，且集中在数字和关键词上
