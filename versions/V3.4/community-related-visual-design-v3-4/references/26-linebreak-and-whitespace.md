# 换行、序号、小标题与留白复查

嵌入容量预检、两次渲染、精修与导出；修改后只回查受影响项，已有选择沿用。个别海报坐标、30px净空或字号例外不作全局默认。

## 1. 标记与小标题

已有步骤优先用①②③、1./2.或独立圆形包住生成数字，保留值/顺序/对应内容，母本原标记与展示标记分存；不把并列项变操作顺序、不凭空加医疗步骤。标记跟本项首行，后续行对齐正文起点；数字有生成证据，圆/短线可为原生图形。

已有小标题分层并靠近所属正文，组间净空大于组内。统一醒目色/加重/短线，仍不清楚可用紧凑细框；完整正文/步骤区是否承托按10决定，主标题禁框。具体独立生成与颜色按21/25，不随机组组换色。

## 2. 语义换行

按短语/句段边界断行，保护否定、条件、范围与动作关系，避免孤字/短末行、闭合标点行首或起始括号/引号行尾；不靠删字、润色或拉伸齐行。英文词、原空格、必要标点完整，省略号/破折号作完整单元；日期/区间/时刻、电话/邮箱按21完整横排，日期过长先拓栏/移位，标签可上移一行。

地址/地点/时间在连续空间足够时优先完整横行；长地址按真实语义断行，不强制全部一行。比较修前后实际行数、字形、行距与阅读路线。

## 3. 空位与实际边界

查看整图及顶部、标题/正文两侧、四角、服务区；紧急组可在顶部或合适角落，按容量/对比/阅读路线/主体保护选位，不固定右下。按当前注册RGBA资产alpha边界测每行/组（含标点、描边/立体边缘），记录剩余宽度、行净空、组距、末行/最长行宽比，并绑定底图/字层版本哈希。

无字像素不代表连续可用留白；墙、脸、屋顶、树叶、影仍可能是主体/复杂背景。局部像素复杂度只是线索，结合保护区复核；无可靠掩膜记目视/未像素测量，不造分割值。行距看实际笔画净空，不用框顶差替代。先调栏宽/位置和碎行，再在可用区域放大字形/疏朗分组，覆盖图片处按10/25选图文处理后查目标尺寸；不填满所有呼吸空间。

## 4. 可选换行记录检查器

从技能根目录运行：`python3 scripts/check_linebreaks.py linebreak-record.json`。只需Python 3标准库。仅检查横排行记录；竖排中文列顺序与竖向标题依10/11模块看图检查，不能把列框作为水平行提交。退出码0为提供的记录检查通过、1为存在失败、2为缺证据或输入无效；不修改图像或文本。

输入示例为估计记录，运行应为unknown：

```json
{
  "asset_version": "example-only-v1",
  "expected_group_ids": ["body"],
  "groups": [{
    "id": "body", "measurement": "estimate",
    "master_text": "请保持通道畅通。",
    "unbreakable_units": ["保持通道畅通"],
    "available_bounds": [0, 0, 480, 180],
    "min_line_gap": 12,
    "lines": [
      {"text": "请保持通道畅通。", "join_after": "", "bounds": [10, 10, 420, 64]}
    ]
  }]
}
```

所有bounds为同一画布上的[x,y,width,height]像素值，必须来自真实字形边界。英文行之间原有空格写入join_after，末行join_after为空。脚本严格重组字符串，不自动剔除空格/标点；不可拆单元由当前母本明确列出，[]表示确无此类单元，省略则该项unknown。

授权标记/安全句读转换按05另存准确展示文案供master_text比对，保留原母本、原因和等价核对；数值、范围、条件、专名功能符号不省略（如3–6岁不能变36岁）。脚本不规范化差异，竖向标题只可用副本核对，不用水平几何检查。

清单缺组、文字不一致、基本标点禁则、不可拆单元跨行、已测行框越界/净空不够会报fail；估计或缺真实行框/可用区域/间距参数会报unknown。短末行只给复查提示，不能单凭比值判断语义或美感。完整条件/专名是否应列为不可拆单元、相邻信息组净空与图像保护区仍由实际审查判断。

脚本不读图/OCR/审美，rendered只是调用者的实测声明，不证明画面显示；像素对比见19，最终仍每语言看整图/局部。
