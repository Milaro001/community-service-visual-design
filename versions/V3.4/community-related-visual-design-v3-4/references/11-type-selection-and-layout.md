## N5a：先选独立艺术主题字

1. 锁定完整标题、语言、底图、受众及语气，按25模块建立语义→字形／配色／组块关系。各语言分别制定提示、独立生成；英文先选TG库真实拉丁字例，T04补充词组结构，不直接翻译中文图或替换字母。
每款生成前留下具体语义设计：`关键词/含义→笔形或笔势→组块/阅读节奏→可见辅助关系→当前底图适配`。五款至少有三种不同的语义表达方法；如“同行”可用相互呼应的字组，“向前”可用上扬笔势，“邻里”可用聚合又保持字腔的关系。每款默认将完整主题字与少量可见语义辅助共同生成，不能只用大小/排列变化交付孤立字形。选与关键词有解释关系的侧边符号、短线/曲线、收笔延展、方向/节奏痕迹或微型情节；数量与复杂度按主题克制处理，不套通用花/星/箭头。辅助可独立贴近、呼应或沿笔势延伸，不要求连接每个字符，不替字或遮字腔；只换色、普通居中组合或无关小图不算完成。严肃主题保留完整字义和清楚字符，不用图形替字或冒充规范符号。

把具体辅助元素及含义、相对位置、形态/色彩和保留边界写进本款生图提示，与准确标题及笔形/组块方案同次出图；现有参考缺装饰时可据当前语义原创，不以semantic_device_observed为空为省略理由。例如“随风去野”可用字侧风线/舒展收笔，“邻里同行”可用相互呼应的短弧/连线，按本轮语义创作。不能只写“有趣/加入小装饰”，也不能把N6正文功能图标当作标题语义辅助已经完成。同步保存文字识读区与完整字组边界；工具分层时同组关联，后续不只裁取字的主体而丢掉符号/细线。生成缺辅助时只定向补修本款，不重生整组已通过候选，不增加选稿轮次。

2. 每种实际语言默认5款：3横H1/H2/H3＋2竖向V1/V2。已符合要求的候选可复用，标明来源并沿用稳定编号（已有A/B/C可保留），不重复同风格凑数。横排组合差异依25模块；竖向两款采用不同结构，顺序、完整英文词组和功能标点依[05模块](05-style-spec.md#竖排阅读顺序)。
3. 五款在笔形、装饰复杂度、图形关系、排布和配色上形成可见差异，避免同一粗字/描边/立体效果只换色或排列。主题适合时可探索克制编辑、几何构成、书写动势或其他兼容表达，不指定固定风格配额；手写、细衬线、窄斜或装饰方向仍可用，以实际识读为准。字义图形只辅助字符，逐字／词检查错漏、重复、词距、变形、透明度和裁切。
4. 候选展示前，复用当前字层在已选底图适合区域作轻量叠放检查，按预计合成缩放和显示尺寸查看完整标题及语义符号/线条是否实际出现、贴近关系是否成立、透明裁切/缩放后是否保留，同时核查字腔/笔画粘连、相近字、英文词距及局部对比；方法按[19的两条检查线](19-final-color-and-readability.md#两条独立的检查线)，只记当前标题的真实证据。明显难读或低对比先定向修受影响字组/颜色，不用装饰效果掩盖。此处不制作完整海报、另生底图或增加选稿；已有同版本证据复用。保存源资产、母本、提示、参考依据和检查结果，再按[22模块](22-selection-overview.md)展示实际编号总览/必要局部，图外标风格与简短理由，不提前替用户选字。
5. 单独询问各语言主题字编号；可在同一个主题字问题中分别选中／英文，不能与整体版式选择合并。允许组合、修订；推荐或沉默不是选择。已选沿用，用户要求更改组合／对齐时修订，不由旧选择阻止修改。

## 完整排版入口

主题字选定后先依[21](21-body-type-size-and-spacing.md)派生正文并完成当前同图合览满意/下一步确认，再执行[13](13-layout-workflow.md)的容量、两次渲染审查及完整候选流程。已确认字组按[18](18-full-art-type-and-required-icons.md)复用；位置/面积见10，结构差异见25，验收见15。完整候选依[22](22-selection-overview.md)展示并单独选择，不重复主题字选稿。
