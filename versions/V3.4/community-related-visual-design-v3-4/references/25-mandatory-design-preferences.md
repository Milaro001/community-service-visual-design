# 强制设计偏好与冲突覆盖（2026-10-14）

本文件是当前用户强制偏好的权威来源，用户后续明确要求优先。旧主体35%–45%／目标40%、强制字后柔化、全面禁正文承托形状、可选标题分隔线、75／70px服务字及85–100px行动字均不再默认适用；历史数据仅作历史。

## 1. 主题语义、大小与真实组合

主题字按[24模块](24-type-generation-references.md)完成全库巡览/匹配，文字与少量语义符号/线条作为完整字组同步设计生成，方法与展示前检查按[11模块](11-type-selection-and-layout.md)。正文的继承/简化按21、普通图标与正文/底图的协调按07；轻度风格建议嵌入原流程，不增加固定风格配额或确认节点。正文、小标题及日期号码沿用已选主题字和本轮匹配记录；来源不适配才补查具体字例，不再逐组巡览全库。

完整主题字紧致外接矩形占画布25%–35%，各语言实测，口径见[10模块](10-position-and-whitespace.md#标题和主体的面积)。标题不加底框。3款横排至少1款整组共左边缘、自然右参差，至少1款明显错落／大小字／组块关系，第三款采用有语义依据的其他组合，不能全逐行居中；2款竖向依[11模块](11-type-selection-and-layout.md)。已有笔形可复用，用户改组合时照其要求修订。

## 2. 骨架先行、近似实例与分散排版

先按[09模块](09-reference-library.md)巡览布局全库，再依[28模块](28-background-composition-planning.md)规划主体/文字/服务空间。优先P01–P23与A/B近似结构，记录骨架→具体原图/子图→本次信息组映射并跨阶段复用；无适合项才补其他来源。参考黑白、微小字或空画面不成为默认。

适配参考的相对字形大小、栏宽、分行、行距／组距、横纵分散程度、阅读路线及分隔线，当前完整文案和可读性优先，不照搬难读小字。3款完整版式在标题锚点、轴线、正文栏数／分组／分布或阅读路线形成可见结构差异，不只改页脚或平移仍居中的标题。

## 3. 主要主体与环境分量

新底图规划分别记录主要人物／建筑／物件约占画布35%，加云、草地、树木、地面及四角场景后的图画环境总量约45%、接近但不到50%。已选主图进入排版后锁定相对画布的可见尺寸、宽高比与完整轮廓，不独立缩放或裁切；整幅等比导出不改变其占比，也不为追凑规划值改已选主体。不是机械45%–50%硬区间；不混算两项。纸纹、纯色、透明容器、空外接矩形不计图画。

不缩主体腾文字区；四周须有主题协调的环境延展，可用四角淡化场景／虚影，按主题选择，不强塞所有元素或编造地图、服务点、标志、机构。主要人物、关键物件／动作关系清楚。可靠掩膜才分别实测有效图画像素；目视则记范围、依据及unknown，不用满版文件、提示或放大导出冒充证据。编辑、排版、导出复查两种分量。

## 4. 图文一体构图与按需承托

优先在锁定主图尺寸/比例下调整完整文字组的位置、轴线、栏宽、语义断行和组距，利用连续留白排清楚；能靠排字解决就不用承托框。其次按需减弱画面周边的树、草、枝叶等非关键环境，再依据[10模块](10-position-and-whitespace.md#正文承托与形状选择)考虑少量协调形状。整段正文矩形底板是后置选择，不是长文默认；短警示/地点细框按实际功能保留，不需新开框形选稿。主标题禁底框仍适用。

周边环境已获准适度降低透明度/细节/反差或轻微虚化，只作用实际周边环境图层/局部遮罩，渐变过渡保留场景联系。先圈定主要人物/物件、完整主体边缘、关键动作及实际视觉中心为保护区；靠边的主体也不能淡化。周边范围依真实构图，不用固定比例，也不能把几何画布中央当作唯一视觉中心。所有处理包括羽化/模糊扩散均不得侵入保护区；不降低整张底图透明度、不整图模糊或在中心字后刷白/虚化，文字、数字、图标保持清楚。

承托确有需要时与主题/环境建立层次，不能为融入一个突兀矩形去模糊视觉中心。记录排字方案、主图锁定尺度、环境处理范围/方法/强度和保护对象；实际看整图/局部检查渐变边界、中心清晰度、主体尺度及最差文字对比。无可靠区域划分则先重排或采用可控区域编辑，不冒充自动掩膜。可读留白无需重复处理。

## 5. 强制横线分隔

主标题与其后预警／提示或行动正文必须有清楚横线；独立预警组与行动区之间用合适短横线；服务区上方保留清楚横线。依字组宽度、轴线与疏密设置，留足字／图标间距，不穿笔画／人物、不围标题成框、不每行机械划线。候选和导出检查区分是否清楚；线与地点框的细节依10模块。

## 6. 相近文案量的正文95–110px

以3200×4000px成图为基准，约4项行动、1个预警和地点／时段／咨询信息的少量至中等文案：行动说明及服务正文采用95–110px可见字形，默认约100px，数字至少同等辨识分量；小标题可更醒目，特殊强调号码可稍大，主标题独立按面积量。

数值是最终主要字形可见像素高度，不是行框、素材页、CSS px或真实字体pt。中文量主要完整字面；英文分别看主要字母与小写x-height／字腔，不靠升降部或多行高度充数。其他画布按宽度相对3200px换算后检查。

按语义／语言分行，完整保留否定与条件，不孤立标点或拆英文词；日期、时段、电话、邮箱保持完整横排。先调栏宽、位置、分行，不压扁、删文案或继续缩字齐行；更密任务先重排，仍冲突再说明约束，不恢复旧小字档。组内笔画／升降部不碰，组距大于行距，依近似实例分散信息。日期同行细节见[21模块](21-body-type-size-and-spacing.md#语义小标题独立生成与日期同行)。
