# 选稿总览与选择语义

现有选稿顺序：检查本轮候选→制作真实编号总览→展示总览/必要单图或局部→用同编号提问→等待真实选择。适用于底图、各语言主题字、标题正文合览确认、完整排版、精修配色等；已选方案沿用，授权修改不强加新选择。

## 总览

- 全组当前实际图等比合成，不用描述/空位/旧稿代替；排布按数量与横竖比例选并排、纵排或网格。全部候选完整保留，无拉伸、裁字/主体/页脚。
- 左侧或左上独立外标签编号清楚稳定：底图A–C；主题字H1/H2/H3/V1/V2；标题正文单一合览用当前版本ID，不让用户选正文方向；整体L1–L3（扩展至L4/L5）；配色A/B。多语言可加ZH/EN。文件、聊天选项和状态表映射一致，不随完成顺序变化。
- 标签与图之间留间距，不压图。透明主题字以含语义辅助的完整字组边界展示，不裁掉离散符号/细线；用同一清楚预览底色、保留alpha，预览背景不烧进原资产；横/竖方向不互相旋转。
- 总览过密则扩大尺寸/分区并补细览，不能省整组或仅轮播；小字另给原尺寸局部/单张，总览不替代正文校对。
- 外部编号、方案名、前后标记可用普通字体，只作审阅导航，不进入交付文案。保存总览与候选ID/文件/版本对应表。

实际打开总览，检查数量、编号/顺序、有效版本、完整等比显示和标签可读；错配/未生成先修再问，无合成能力如实记未完成，不用文字列表称通过。

## 选择

采用只来自用户对当前编号/版本的明确答复；推荐、纯评分、沉默或暂不采用不代选。合并/调整、全部重做按范围修改，更新真实候选后再选择。网页选择规则见[30](30-human-review-and-feedback.md)，两图胜负不替代全组选稿；内部审核与用户选择分开记录。

候选数量/风格与主体位置覆盖分别由[主流程](../SKILL.md#执行流程)、[29底图覆盖](29-background-style-and-position-coverage.md)、11/21/19定义，本文件只负责总览和编号。
