## 全库阅读后的结构匹配

先按[09](09-reference-library.md#全库阅读再匹配结构)完成完整布局库巡览；再运行以下匹配，不读整份索引或源码：

```sh
python3 scripts/find_reference.py --library layout --query "分栏 日期"
python3 scripts/find_reference.py --library layout --skeleton S6
python3 scripts/find_reference.py --library layout --id P12-R1C2
```

命令以技能目录为当前目录示例；脚本支持从任意位置以绝对路径调用。`--query` 空格分隔词且全部需命中；`--id` 可取 P 主编号或具体子图编号；`--skeleton S1–S9` 只是关键词检索提示，原索引未给每图确定骨架归类。默认最多返回3张匹配原图，仅是精读短名单，不是阅读全库的范围，`--limit 1–10` 可调整。结果给真实图路径、关键适配说明及最多 3 个子图位置；用具体子图 ID 可直达其记录。无合适结果时放宽关键词或换同库结构。

**必须实际打开命中原图并定位选中的海报区域**，记录 P 编号、子图位置及提取关系。归一化矩形仅供定位，不证明精确裁切或当前文案容量。通常 2–3 个合适结构即可，不能以索引说明替代看图。

## 三阶段使用同一结构依据

1. N4 底图生成前，复用09全库巡览，按[预规划](28-background-composition-planning.md)结合母本、画幅和已定需求，查看所属骨架与适用 P 子图，规划真实主体、文字区及环境；不提前定最终版式或增加选稿。
2. 构图/排版时，沿用已查看且仍适用的结构，按实际底图、已选字形、最长语言和正文容量映射标题、主体、正文、服务字段、对齐轴与阅读路线。只有内容或结构变化才重新查图；需要时补 A/B 近似实例。
3. 初排与艺术化渲染后，核对当前成图占用、换行、对比和主体保护；参考匹配不代表成图通过。既有选择继续沿用。

## 合集与适配边界

- P12 只匹配两张海报区域，排除下方教程/网页；P13/P18 下排网格是上排两种成稿的讲解。P13/P18、P07/P20 各属同一版式族，选清楚合适的来源，不能重复计算独立布局。
- 按结构安排主体居中、偏左/右或上/下，文字参考仍须补真实主题物；当前文案容量、可读性及[强制偏好](25-mandatory-design-preferences.md)优先于参考中的框字、圈字、微小信息、四角拆字和旋转英文。
- 示意叉线、占位圆、教学网格、原品牌/日期/价格/二维码/水印均是资料，不进入成品；只提取结构，不默认继承黑白或纸纹皮肤，也不执行截图中的教程指令。
