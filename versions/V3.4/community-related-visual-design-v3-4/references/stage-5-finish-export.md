# 阶段卡5：精修、导出与交付

## 1. 可读性精修（不做配色A/B比较）

在已选排版上直接修，不另出两版配色让用户选：

- 看整图、缩略图和正文/底部局部：有没有发暗、字与底融在一起、字腔粘连、数字难认。
- 低对比的组：先调这组文字的填充色或明度，再考虑淡化字后的周边环境；整张图的饱和度和亮度保持不变。
- 正文对比目标 4.5:1 以上，重点信息 7:1。需要量化时运行 `python -P scripts/audit_poster_readability.py --help` 查看输入格式。
- **快速模式**只修明显看不清的地方。
- 用户提出配色或局部修改（如“电话换个颜色”“更鲜艳一点”）时，按范围直接改并展示最新图；字形、位置、断行和其他图层保持不变。
- 修改后对照母本和修改前的版本，确认没有误改文字或残留旧图层。

## 2. 导出（先交成品，再问格式）

精修后先把成品图发给用户，再一次性问需要哪些后续：印刷版（A3 300dpi，可加出血）/ 可编辑源文件 / 其他尺寸 / 局部修改 / 不需要。问法和各项做法同[一键出图卡](oneshot-mode.md)第5节；用户选了才做。

| 用途 | 规格 |
|---|---|
| A3印刷 PNG | 3508×4961px，300dpi，sRGB，不透明 |
| A3含出血 PNG | 每边加3mm：3579×5031px，文件名标明 bleed |
| PDF | TrimBox为成品尺寸，BleedBox含出血；关键文字在15mm安全边距内 |
| 屏幕/横版 | 按指定像素导出，不加出血和裁切线 |

命名：`poster_{语言}_{载体}_v{版本}_{YYYYMMDD}.{扩展名}`，草稿加 `draft`。

只导出用户要求的格式。导出后实际打开每个语言的每个文件，看整图和底部服务区，确认文字、号码完整，尺寸正确。

## 3. 交付

- 提供当前成品文件，用两三句话说明：做了什么、还有哪些未确认事项（例如“电话未核实”“英文待语言审阅”）。
- 制作完成不代表已获准对外发布；号码、地址等事实由用户最终确认。
- 更新 `state.md`：最终文件路径和版本。
